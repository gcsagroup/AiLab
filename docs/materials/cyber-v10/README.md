## 完整包的取得和使用

完整包尚未随本 PR 上传，也未创建下载地址。接收负责人向材料提供方另行取得以下三个同名文件，取件联系人与地址尚待登记，见 [交接清单](handoff_manifest.json)：

- `网安SFT与RL_负责人交接包_v10_全文初审版.zip`
- `网安SFT与RL_负责人交接包_v10_全文初审版.zip.sha256`
- `网安SFT与RL_负责人交接包_v10_全文初审版.receipt.json`

ZIP 大小为 **166,763,672 字节**，SHA256 为：

```text
7beddd6bbaef1adedcaef3eaa775fa5cd6a2107810c646a21d6568ffa8f914d6
```

1. 取得文件后，先核对 ZIP 摘要与上述值、外部校验文件是否一致。Windows 可使用 `Get-FileHash -Algorithm SHA256 -LiteralPath '<收到的ZIP路径>'`。
2. 解压后先读包内 `00_交付说明.md`、`01_全文初审与暂缓策略.md` 和 `02_负责人确认事项.md`。
3. 在解压后的负责人包根目录，用 Python 3.12 运行 `python verify_handoff.py`，应得到 `status=passed`。该核验只读本地文件，不联网、不训练、不启动服务或 Docker；内部清单覆盖 780 个被校验文件，归档总数另包含清单自身。
4. 数据入口以包内 `当前材料_v10/assets_index.json` 为准。本仓库索引应与它逐字节一致。按 [数据说明](DATASET_INDEX.md) 选择单一数据族和划分，先保留 32 条 smoke 供后续验收。
5. 审核证据和原 v9 包供追溯，不混入训练。RL 构建材料由后续环境负责人取得并评审，不自动执行。

以上是后续使用说明，本次 PR 不执行实际导入、模型训练、环境构建或部署。
