# GCSA AI Lab 用户操作手册

本手册对应当前公司签名候选 Ver2.4（032）。可以继续既有任务、查看和编辑作品修订、加载更早历史，并导出明确选择的版本。正文与配音文案各支持最多 16000 字符，字幕最多 200 条。029 已接受 Media 三入口在两个既有任务中的四个原生实例、正反向 Tab、Enter／Escape 回焦、正常退出与一次停机读回的有限子集（E137）；没有执行真实导入或模型运行。028 工作台四按钮的既有有限接受保留。详见[028进度](implementation/2026-09-15-ver2-4-028-workbench-keyboard-progress.md)、[Media进度](implementation/2026-09-15-media-keyboard-progress.md)和[候选范围](implementation/2026-09-10-ver2-scope.md)。

032 已验证 Python 符号链接原路径选择、三环境保存、同号同库重开及恢复内置。保存前仍须核对确认框与所选环境路径一致；不一致时请取消。外部环境保存成功不等于依赖齐备或模型可运行，本轮外部探测失败保留，恢复内置后显示就绪；本轮未执行模型或诊断导出。031 的原路径失败保留历史记录。 [032 进度与边界](implementation/2026-09-16-ver2-4-032-python-path-preservation.md)

030 的工作库连接隔离修复已通过源码、签名包和两项包内真实控制服务测试。切换或重启时，旧连接的普通 API 请求和媒体读取会失效，写入不会自动向新库重发；请等待当前连接恢复后再操作。原生备份、目标库启动失败回滚、成功切库、分别保存项目及同号重开的有限子集已获根接受；文件、目录和 Python 环境选择器的异步竞态未覆盖。[030 进度](implementation/2026-09-16-ver2-4-030-connection-isolation.md)

可以使用 Tab、Shift-Tab、Return 和 Escape 操作已覆盖的键盘路径。027 的文字原作品纯键盘导出与同号重开、028 的工作台四按钮原生路径均为有限验收，不代表所有页面和任务已经完成键盘验收。011 曾在开启 macOS“键盘导航”后检查弹窗焦点并恢复原设置，该条件仅属于[011历史记录](implementation/2026-09-13-ver2-2-011-progress.md)。

011 的窄屏、独立空库、隐藏重开和初显计时保留历史归属，不转记为 028 性能结论。界面出现后，运行前仍须等待相应检查完成。020 曾出现的长列表空白尚未定位；指定设备、跨主机、干净安装、达标质量和五名首次用户等完整验收仍未完成，详见[交付矩阵](implementation/2026-09-10-current-delivery-matrix.md)。

来源组划分从 Ver2.2（006）候选开始提供，005 不包含此功能。下文相关步骤已用七行原件及真实 tokenizer 完成[指定原生流程验收（E72）](implementation/2026-09-10-current-delivery-matrix.md)，包括完整备份恢复后继续原预览。此次不加载模型训练，不代表模型质量或验证损失通过。

## 1. 获得第一个结果

1. 打开 App，新建项目。项目分别保存模型、任务、数据和作品。
2. 在首次使用引导中选择“准备官方语言模型”，查看来源、许可、固定版本和下载清单后开始下载。当前固定语言模型约 953.3 MB，界面建议预留约 2 GiB。
3. 下载中断后，在“模型库 → 模型准备记录”打开同一条记录并继续。已下载的有效文件保留；文件完整后仍需点击“加入当前项目模型库”。
4. 选择“用此模型开始试用”，或在引导中建立示例草稿。示例是一段可修改的普通文字输入。
5. 点击“检查配置”，确认模型、设备和配置；检查通过后点击“开始运行”。下载、登记、保存草稿都不会自动运行模型。
6. 输出完成后点击“保存作品”。任务与原配方自动保留；作品可在“作品与素材”查看和导出。

无需首次下载也可使用“导入模型”，选择已有的完整模型目录。只有检查通过的精确组合可运行；文件完整不代表回答质量通过。

## 2. 修改任务与运行设置

1. 在工作台选择类别，再点击“继续上次运行”或“继续上次训练”；也可从“任务与结果”或右上角“任务队列”打开指定任务。要建立另一份任务，使用“新建试用”或“新建训练”。列表末尾的“加载更多任务”用于继续查看更早记录。
2. 修改输入或展开“运行设置”。草稿会自动保存；若提示保存失败，点击“保存草稿”重试，确认显示“草稿已保存”后继续。旧结果仍对应原执行时的模型与参数。
3. 使用预设时，先选择“运行预设”，点击“预览预设差异”，确认后选择“应用到草稿”。应用只修改配置，不运行模型。
4. 点击“检查配置”，通过后再明确点击“开始运行”或“开始训练”。运行中、暂停中或停止状态待核实时，配置保持只读；先处理原执行，再继续修改。

语言生成可以设置最大输出、温度、Top-p、种子、上下文总预算、停止序列和流式显示。上下文预算包括模板、输入及最大输出预留；超限时拒绝运行并保留输入。当前只提供单条输入，不裁剪历史对话，固定 Qwen2.5 组合没有思考开关。

停止序列每行一条，最多 8 条，每条最多 128 个字符。空行忽略，首尾空格保留；命中后停止且不显示该序列。关闭流式只改变显示时机，最终结果、运行状态和停止操作仍保留。

默认配置优先用于建立基线；低内存预设可能让首字更慢，低延迟效果取决于输入和当前设备。4-bit KV 缓存的既有质量验证失败，当前不可选择；它与模型权重量化是两项不同功能。

## 3. 微调与评测

在语言或图片工作台选择“训练 / 微调”，导入基座与数据，检查样本和参数后明确开始。语言当前为固定 SFT + LoRA；图片当前为 Tiny-SD 的 LoRA。视频和音频训练尚未开放。

005 候选已验证的语言训练表单从当前执行位置的配方读取参数范围，显示默认来源、固定批量和步数停止条件。读取配方不会检查设备、连接远端或覆盖已填内容；读取失败或已有值超出当前范围时，先修正或重新读取，再检查配置。当前本机与 NVIDIA 组合均最多200步、每设备批量1、梯度累积1、单个数据并行设备；NVIDIA学习率至少0.000001，LoRA Alpha必须是整数。本机保留自己的范围，切换位置后不会把不兼容值静默改小。

语言质量验收应在训练前创建并冻结评测计划，再把计划绑定到训练草稿。评测集与训练集分开，保留业务、格式、正常能力和目标行为四类问题。训练完成只表示产生了独立适配器；未达标准的产物仍是实验适配器。

评测会分别加载基线与候选，显示逐条输出和判定。训练后的临时对照可用于分析，但不能代替预定准入计划。只有通过预定门槛并明确登记后，才使用“质量通过”的候选；该结论仅覆盖相应模型、评测集和设备。

支持暂停的训练需等待界面确认暂停后再继续。停止后若存在可用检查点，可创建恢复任务；恢复任务保留来源和固定训练配置。停止状态待核实时，先核实或补收原运行，避免另起一份重复计算。

### 3.1 按来源组准备语言训练数据（006 候选新增）

原件使用 UTF-8 JSONL，每行只包含 `source_id` 和 `messages`。`source_id` 是非空来源标识；来自同一原始记录的不同问答必须沿用同一个值，不能为了划分给每条变体另编来源。同一来源组的有效样本会完整留在训练或验证一侧。下面三行展示两条同源变体和一条独立来源：

```jsonl
{"source_id":"订单-001","messages":[{"role":"user","content":"订单001什么时候发货？"},{"role":"assistant","content":"订单001将在周五发货。"}]}
{"source_id":"订单-001","messages":[{"role":"user","content":"请确认001号订单的发货日。"},{"role":"assistant","content":"发货日是周五。"}]}
{"source_id":"订单-002","messages":[{"role":"user","content":"订单002可以修改地址吗？"},{"role":"assistant","content":"订单002尚未发货，可以修改地址。"}]}
```

1. 在“数据集市场 → 我的数据”点击“导入语言数据”，选择原件；在原件卡片点击“划分训练与验证”。训练草稿选择原件后也有同名入口。
2. 选择用于分词检查的模型、最大序列长度、固定划分种子和验证比例。当前支持固定 Qwen2.5-0.5B-Instruct 原权重的分词资料；长度须与之后的训练设置一致。
3. 点击“检查并预览划分”。检查只在 CPU 上分词和核对监督范围，不加载模型权重、不训练。查看有效及排除样本、两侧来源组与样本数、请求和实际验证比例、排除原因及新增文件范围；需要时展开最多三条词元和监督标签证据。
4. 确认没有阻断项后，点击“应用划分，生成新版本”。应用登记独立的训练子集、验证子集和来源证明，原件保留；此时训练草稿还没有自动改变。
5. 在训练草稿的划分窗口点击“使用训练子集”，或从数据卡片的训练子集点击“用于训练”。保存草稿，再“检查配置”，最后明确开始训练。其他已填参数保留，仍须满足当前模型与执行位置的范围。

新语言 SFT 训练强制使用已应用划分的训练子集（`train`）。原件、验证子集和未应用预览都不能直接提交新训练；换模型分词资料或改变最大序列长度后，须从原件重新检查与划分。已有历史检查点只按它原来冻结的配置恢复，不因此获得来源组隔离证明。

零监督、超长及不支持的媒体或工具样本会先排除；超长样本整条排除，不截短后混入训练。至少要有两个含有效样本的独立来源组，两侧均非空。划分按组进行，实际样本比例可能偏离请求；发现两侧存在规范化后完全相同的用户提示词会阻断应用。语义近似去重尚未检查，来源标识仍需由准备数据的人核实。

验证子集目前用于留出隔离和检查，尚未计算验证损失，也不代替独立质量评测或证明模型质量。默认 NVIDIA 训练上传只包含训练子集；划分证明随训练配置固定。

### 3.2 找回预览与处理检查中断

预览准备好后可以关闭窗口；再次从原件打开“划分训练与验证”，在“已有检查与预览”读取原记录。重启或恢复工作库后也从这里继续，读取记录不会重新分词、应用或训练。

检查中需要停止时，点击“取消本次检查与预览”，等待界面确认停止。若显示“上次检查被中断”，先取消旧计划并核实结果；需要新检查时再选择“保留参数，重新预览”。连接中断后沿原记录重新读取或“重试上次操作”，避免反复新建。已应用结果若提示部分暂存尚未清理，可以“重试清理暂存”；正式子集已经登记，此操作不会生成第二份划分。

## 4. 图片、视频、配音与工作流

图片使用文字描述生成；视频使用已导入的 PNG 素材，或把已保存图片用于视频任务。当前固定视频组合输出约两秒短片，既有样例运动很弱。中文配音使用固定小北音色；生成文件可播放和导出，仍需自行检查内容和发音。

商品工作流按图片、视频、配音分步执行。每步先检查再开始，接受本轮结果后进入下一步；复用旧结果必须明确选择并确认来源。修改上游后，下游会标记过期，需要重新检查。整轮保存会分别保存三项作品，当前没有合成一条带配音成片的功能。

## 5. 修订与导出

1. 在“作品与素材”的作品卡片点击“文字修订”“配音文案修订”或“字幕修订”。窗口默认查看当前版本，可在“查看作品版本”切换原版或已加载的修订，查看正文、父版本和与父版本的差异。
2. 首次列出最近最多 100 条修订。需要更早记录时点击“加载更早版本”，当前正在查看的版本保持；重复加载直到找到所需记录。若提示作品已有新修订，点击“重新读取作品版本”，再重新选择要查看的版本。
3. 要编辑时，先选择当前版本，再点击“编辑当前版本”，焦点会到首个编辑字段；没有字幕时到“添加字幕”。完成后选择“保存独立修订版本”；不保留本次修改则选择“取消本次编辑”，焦点回到编辑按钮，可直接按 Return 重新编辑。保存会新增独立版本，原版和旧修订保留。若保存提示已有其他修订，本次输入仍保留；确认不再需要这些输入后，才点击“放弃本次编辑，读取当前版本”。
4. 编辑中按 Escape 会显示退出确认并聚焦“继续核对”。按 Return 可返回之前仍可用的输入；只有确认放弃时才选择“放弃未保存编辑并关闭”。

| 内容 | 上限 |
| --- | --- |
| 文字正文、配音文案 | 各 16000 字符 |
| 单条字幕 | 500 字符 |
| 一份作品的全部字幕 | 最多 200 条，总文字最多 16000 字符 |

按界面显示的字数核对；扩展汉字“𠮷”计一个字符。超限输入不会被提前截断，但保存前必须缩减到上限内。字幕开始与结束时间使用秒，须按时间排序、互不重叠，并位于原视频时长内。

长字幕可逐页滚动，也可收起“与父版本的差异”缩短内容。021 已核对展开／折叠差异时的逐页、大幅和上下边界滚动，背景作品页保持原位，关闭后背景仍可滚动。020 曾出现的两帧空白根因未定；若再次遇到，可先尝试常规上、下一页滚动并保留问题记录，不能据此认定问题已修复。

文字修订不改变原生成配方；配音文案修订不改变声音；字幕保存为独立 VTT 文件，不烧录进视频。窗口内的播放器始终播放原始媒体。

导出修订时，先在“查看作品版本”选定原版或某个修订版，再点击“导出所选原版”或“导出所选修订版 N”；作品卡片上的“导出原作品”始终导出原版。选择保存目录、检查文件范围，最后点击“开始导出”。只有全部文件写入并校验后才显示完成和保存位置；旧修订导出不会自动改为当前版。修订版导出保留原媒体、独立文字／字幕和版本记录。

模型、适配器和评测报告也有独立导出入口。适配器包记录所需的精确基座，不默认包含基座权重；在其他工具使用前，应按清单准备兼容引擎和依赖。临时或未完成目录不能当作完整导出包使用。

006 及后续候选的训练／验证子集卡片提供“导出划分”，划分窗口也可选择“导出原件、子集与证明”。先核对预览，再明确导出；数据包包含原件、两个子集、来源组及检查证明和对象说明，原文与来源标识会一并导出。导出不会重新划分或训练。普通训练报告和适配器包只携带固定划分身份，并列出完整数据包这一外部依赖，不默认附带原件或验证数据，也没有验证损失结果。

## 6. 数据市场与 AI 辅助

训练草稿可打开数据集市场，检查提供方条目、版本和访问条件。需要申请的条目必须等待提供方批准；批准后下载、检查，再返回原草稿使用。原任务的其他参数保留，选择数据不会自动训练。

本轮只验过受控测试提供方，不代表已经连接商业数据市场。下载文件、使用声明和提供方授权分别保留，不能互相替代。

AI 辅助只提出建议。先查看建议与草稿差异，再决定是否应用；应用后仍需手动检查并开始任务。建议生成失败或回答格式不合格时，原草稿保留。当前实际验证的是本机模型建议，未开放的远程连接不继承此结论。

## 7. 备份、恢复与故障处理

从“设备与环境 → 备份与恢复”创建完整备份。先完成运行或停止下载；备份包含数据库、引用资产、原运行记录及停止后的下载缓存。大型模型复制需要时间。

恢复时选择备份和目标目录，查看检查结果后“恢复到新目录”。恢复完成不自动替换当前工作库；确认使用后再点击“切换到恢复的工作库”。原库保留，恢复后的新运行使用本 App 的内置环境。

006 及后续候选使用资料库 v4。完整备份包含来源组原件、两份子集、证明及其关联；尚未应用且已准备好的预览也随备份保留。恢复到新目录后可读取原预览并明确应用，不会重新分词或训练。正在检查、取消中或停止状态未确认时，先处理原记录再备份或清理；缺少文件或划分关系不一致会阻止备份／恢复。

存储清理先列出精确文件范围和大小，再明确执行。当前只移动本库无引用资产，并提供恢复入口；原执行证据和库外下载不在清理范围内。

环境安装或恢复后，在“设备与环境”点击“刷新环境”重新探测。按钮等待期间会禁用；探测失败会显示原因，可再次重试，当前项目和未保存输入会保留。

遇到服务中断，先重新连接并查看原任务。状态待核实或产物待补收时，沿原任务核实和补收；补收不会重新训练或推理。若需要诊断，在“设备与环境 → 导出诊断摘要”预览包含与排除的范围，再选择目录保存。诊断只包含受限状态摘要，不包含任务正文、原始日志、凭据或本机路径。

从 005 起会记录本次控制服务会话最近32次环境探测的结果、耗时、退出码与完成时间，区分超时、无法启动、异常退出和无效输出。023 另记录本次服务环境检查中的等待、身份检查与缓存结果，便于分辨时间花在哪里。预览诊断只读取已有记录，不重新探测；记录可能包含旧配置，服务重启后清空。它帮助说明上次检查为何失败，不能证明当前设备已经就绪。

## 8. 执行目标与文件传输

在“设备与环境 → 执行目标”登记已经启动的独立执行服务，填入目标名称、连接地址、执行器编号和访问凭据。HTTPS 地址只包含主机与可选端口，例如 `https://执行服务主机:端口`；旧的 `http://127.0.0.1:端口` 回环模式继续保留。地址与编号共同固定目标身份，原生 App 使用系统钥匙串保存此目标的凭据；开发浏览器只在控制服务内临时保存，服务重启后需要重新输入。清除凭据会保留目标记录，重新连接需要再次配置。

HTTPS 服务需使用独立执行目录，并显式配置绑定 IP、证书链和私钥，见[执行服务准备示例](implementation/2026-09-10-remote-nvidia-evidence.md#执行服务准备示例)。证书须能由运行时随附的公开 CA 包验证，与登记主机匹配且在有效期内；验证失败会显示原因，不发送项目文件。

“HTTPS 协议连接已验证”或“回环协议连接已验证”表示身份与传输协议可用。当前已完成本机 TLS 协议验证，005 签名包已纳入 HTTPS，原生证书拒绝与目标界面已验；跨主机受信证书和 NVIDIA 实机仍待验收。NVIDIA 任务还要通过实际设备与模型检查，没有可用设备时会阻止提交。

“新文本任务的默认位置”只影响本项目以后新建的文本生成和训练草稿。已有草稿保留原位置，可以在任务的“执行位置”中单独修改；每次修改都需要重新检查。远端首期使用固定 Qwen2.5-0.5B-Instruct 原权重、Transformers、CUDA 和 BF16，检查前可以保留输入，尚不支持的适配器／检查点组合会明确拒绝。

先查看检查结果里的目标、待发送文件、总大小与SHA摘要，再点击“确认发送并开始运行／训练”。检查不会自动上传模型。只有明确开始后才传输已列文件和本次输入；运行记录与配方保存实际目标，凭据不进入配方。

若只验证连接和文件，可在目标下点击“验证文件传输”，选择当前项目的已导入数据或素材，先“检查发送范围”，再“开始传输验证”。这条路径保存副本并核对接收内容，没有模型计算。“查看传输记录”与“加载更早传输记录”可继续核实同一目标的历史。

断线或证书验证失败时显示的是最后取得的状态，不能据此判断远端已经停止。修复连接后沿原记录“重连并核实原执行”；需要取消时也沿原编号请求，只有确认远端进程退出后才表示已经停止。计算完成但接收失败时使用“只补收已有产物”，按原封存清单取回和核对文件，不会重新运行模型。

## 9. 安装与更新状态

本轮开发、原生测试和运行使用同一 App 路径。完整候选每次构建递增括号中的编号；“技术预览”表示验收状态，不是功能版本号。当前 Apple Silicon／macOS 26 及以上是待最终候选复验的系统范围。

本地候选更新工具先生成双方版本、签名、文件和当前数据库的计划，再明确执行替换；旧包及数据库备份保留。使用方法见[桌面构建与更新说明](../scripts/desktop/README.md)。其中数据库备份不含模型等资产，不能代替“备份与恢复”中的完整备份。

005 使用资料库 v3，006 及后续候选会把库升级到 v4，并在迁移前保存一致的数据库副本。005 会拒绝打开 v4 库，不能用替换回旧 App 的方式直接降级该库；需要回到旧版时，应使用升级前保留的兼容工作库和完整备份。迁移副本只包含数据库，不能代替资产备份。更早的 0.1.0 包同样不能直接读取 v3 库。

最终候选的真实安装、升级与失败回滚结果将随对应签名包交付。当前没有自动更新发布通道；本手册不代表独立机器安装或正式分发验收已经通过。
