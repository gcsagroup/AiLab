# Studio 使用说明

## 准备环境与资源

按 [README](../README.md#从源码启动) 启动控制服务和前端。在设置的环境管理页选择 CPU、CUDA 或 Metal 对应环境后安装。训练、HF 消融、llama.cpp、vLLM、Diffusers、ComfyUI 为不同配置。更新创建新版本，不在正在使用的环境上直接覆盖安装。

在资源目录设置模型和数据集目录。模型库展示本地模型；数据集页提供市场、本地数据集和下载任务三个视图。模型的 tokenizer、配置文件和必要的自定义代码需与权重匹配；自定义代码仅在明确允许时执行。

## 数据集市场与本地管理

1. 在“设置 → 资源目录”选择数据集根目录。市场下载按分类存储于根目录的 `market/分类/任务ID/`，本地文件导入保持原位。
2. 进入“数据集 → 数据集市场”，选择 HF 或 Kaggle，输入关键词搜索；也可输入 `owner/name` 后按 ID 打开。当前最多浏览前 100 项。
3. 查看数据集说明、许可及来源链接，选择 Revision 后点“读取版本”。HF 下载固定到解析后的提交 SHA；Kaggle 下载指定版本的 ZIP。修改版本输入后必须重新读取，才可下载。
4. 选择文件、分类和用途，点“下载所选文件”。进入“下载任务”查看进度、暂停、取消或继续／重试。来源不支持 Range 时重新传输当前文件；服务中断后保留部分文件，需手动继续。
5. 下载完成后进入“本地数据集 → 查看文件”，可预览 JSON／JSONL／CSV／TXT 的前 32 KiB，或查看其他格式的文件信息。数据说明显示前 64 KiB，内容不执行。
6. 本地已有文件或目录可通过路径选择和“登记本地数据”加入索引；导入会计算 SHA256。Kaggle ZIP 先手动解压，再导入需要的数据文件；CSV／TXT 需转换为训练器支持的格式。
7. 对具体 JSON／JSONL／Parquet 文件点“用于 SFT”，核对训练表单中的数据路径、模型与参数，然后点“开始训练”。数据格式、聊天模板、上下文长度和监督范围仍须匹配；下载成功不代表任意数据可直接训练。

不要将含 smoke、pilot、元数据或另一数据族的整个目录直接交给训练器，避免递归读取导致重复或误用。需要配套验证集时，准备只含相应 train／validation 文件的干净目录，测试集单独保留。通过市场选择的是单个明确文件，不会自动混入其他文件或自动启动训练。

需要凭据时，在市场页打开“访问凭据”。HF 使用 Token；Kaggle 新版 Token 的用户名留空，旧版 Key 配对应用户名。凭据只在当前控制服务内存生效，重启后重新配置；也支持由启动环境提供。此处不会替你接受来源网站的访问条款。

“移除索引”保留文件；“下载任务 → 清理下载文件”明确确认后删除该任务目录与登记，不处理本地导入源文件。正在被训练任务使用的数据不允许清理。Windows 路径过长时，应选择更短的数据根目录。

## LLM 对话

选择 llama.cpp 或 vLLM；GGUF 可以从已识别列表选择，也可以通过“选择其他模型”打开系统窗口。按需加载模型后发送消息，Enter 发送、Shift+Enter 换行。响应流式显示，思考内容与正式回答分开。图片输入只对配置了视觉支持的模型开放。

参数会自动记忆。新建对话替换旧会话；手动卸载按钮立即请求卸载，空闲超时则自动释放常驻模型。正在生成时需先结束任务。

## 媒体生成

选择 T2I、T2V 或 R2V，再选择权重格式：

- Diffusers：选择完整模型目录。
- ComfyUI：选择架构及匹配的主干、文本编码器、VAE；SDXL／FLUX.1 需要第二文本编码器，Wan 2.1 R2V 还需要 CLIP Vision。

填写提示词、宽高、采样步数、引导强度等参数。Euler 为默认采样器。CUDA 下 CPU offload 默认开启；CPU 上不产生 GPU 卸载效果。R2V 可从素材库选择或导入参考图片。

提交后显示加载状态与采样进度，完成后直接预览并保存到素材库。对不提供逐步回调的 Diffusers Pipeline，界面保留运行状态而不编造采样进度。框架支持范围和模型尺寸约束仍适用。

## SFT 与拒绝消融

SFT 选择完整 Safetensors 模型、数据文件／目录、训练方式与设备。设置学习率、batch size、梯度累积、序列长度和 LoRA 参数后提交，查看损失曲线及结果。超长样本不会静默截断。量化基座限制见 README。

拒绝消融可先运行兼容性检查，它只读取架构信息。普通参数通过表单设置，其余通过高级 TOML 设置。未安装 vLLM 时选择 HF；执行输出实时显示在右侧。任务是否成功以最终状态和结果为准。

## 任务队列

设置中的任务并发默认是 1。超过上限的任务等待，任务记录可查看排队与运行状态、暂停、取消及详情。暂停是进程暂停，可能继续占用内存和显存；它不是断点保存或释放设备资源。

## 素材库

导入图像／视频或查看生成结果，按类型和来源筛选。点击卡片按媒体比例放大，视频可播放。鼠标左键长按约半秒进入多选，再逐项点击或全选当前筛选结果，点击删除所选并确认。退出多选后恢复预览操作。

删除只处理素材库副本，不删除导入源或原始任务输出。排队、运行或暂停中的任务引用素材时会拒绝删除；部分失败会保留失败项并显示原因。

## 当前限制

评测与量化页面为空；环境集仅打开现有外部控制界面。视频、CUDA、MPS、vLLM 及指定模型训练／消融的验收范围请以 README 为准，不以配置页截图判断支持状态。
