## 1. 开始使用

在已准备好运行环境的 App 中新建项目，选择文字试用。首次使用可选择准备官方语言模型，先阅读来源、许可和下载清单。下载完成后还须加入当前项目模型库；也可导入已有的完整模型目录。选择模型、输入内容，点击“检查配置”，通过后再点击“开始运行”。保存作品后，可在“作品与素材”查看。下载、导入和保存草稿都不会自动启动模型。

## 2. 任务与参数

从工作台或任务队列继续任务。草稿自动保存；保存失败时先重试并确认已保存。旧结果保留原模型和参数。预设先显示差异，应用后仍需重新检查。语言参数包括输出上限、温度、Top-p、种子、上下文预算、停止序列和流式显示。上下文预算包含模板、输入和输出预留，超限会拒绝运行。停止序列每行一条，最多 8 条，每条 128 字符。低内存预设可能更慢；4-bit KV 缓存当前被阻止，与模型权重量化不同。列表末尾可加载更早任务，全部加载后保留完成提示。

更小的提示词分块不保证更快，输出也可能变化。需要复现结果时，固定分块上限以及模型、精度、采样参数和种子。

## 3. 训练与数据

语言微调使用固定 SFT + LoRA 配方；图片 LoRA 仍属实验功能。导入数据后检查格式和有效监督样本，按来源组划分训练与验证数据，避免同源样本泄漏。先预览划分再应用，原件保留。修改数据、模型或参数后需重新检查。训练前冻结评测计划，分开保存训练和评测样本；评测对照基座与适配器。未达到门槛的结果保留为实验适配器，不登记为质量通过的候选。暂停或恢复以界面确认和可用检查点为准。

2026-10-13 质量补充：现有 Qwen2.5-7B-Instruct 已在独立本地推理中完成 50 条合成运维记录的基线及两轮提示词试验，未进行训练。新提示词改善了部分字段，但仍有事实遗漏、状态错误，修正轮还被原文误导附注诱导而伪造操作与恢复；两轮均未采用。这些样本已用于调试，未经独立业务复核，不能作为盲测或生产质量通过的证据。

整理业务记录时，JSON 格式正确不代表事实正确。应逐项核对服务与节点、时间、已执行操作、后续进展及恢复依据，尤其不要把原文中的建议、否定或命令式附注当成已执行事实。2026-10-13 的合成运维记录试验未通过采用门槛，相关输出仍需人工复核；该试验不是原生 App 的质量验收。

## 4. 媒体与工作流

本轮媒体范围为图片生成、短视频生成及配音，使用上表指定模型与环境。图片 → 视频 → 配音工作流保留各步输入和结果；修改上游输入后，旧下游结果会过期。需要复用时明确选择旧产物，不把它当作新生成。现有样例仍有质量限制，请实际检查图像、声音和视频。

## 5. 修订与导出

文字正文与配音文案各最多 16000 字符；字幕最多 200 条、总计 16000 字符，单条最多 500 字符。字幕时间以秒计，须有序、不重叠且在原视频时长内。文字修订不改原生成参数，配音文案修订不重新合成声音；字幕导出为独立 VTT，不烧录视频。在版本列表选定原版或修订版后导出，作品卡片的原作品导出始终使用原版。选目录并检查范围，全部写入和校验后才算完成。适配器包记录精确基座依赖，不默认附带基座权重。数据划分导出会包含原文和来源标识，导出前确认范围。

## 6. 数据市场与 AI 辅助

市场条目按提供方的访问条件下载；批准不代替文件检查或使用许可。完整下载的版本可在“查看已下载数据”中检查并导入，随后明确用于当前任务。商业数据市场的完整集成尚未验证。AI 辅助先展示建议与差异，由你决定是否应用；应用不会直接运行任务。

## 7. 备份与恢复

在“设备与环境 → 备份与恢复”创建完整备份，先处理运行、下载和停止待确认的记录。完整备份包含数据库及引用资产，大模型需要额外空间。恢复先写入新目录，再明确切换到恢复库，原库保留。单独的数据库迁移副本不含全部资产，不能代替完整备份。旧 App 未必能读取新库，降级必须使用兼容库和升级前备份。存储清理先预览范围，只处理本库无引用资产，并提供恢复入口。

## 8. 远端执行

在执行目标中登记服务地址、执行器编号和凭据。HTTPS 证书必须有效并匹配主机；连接通过不表示 GPU 或模型可用。项目默认位置只影响新建文字任务，旧草稿保留原位置。开始前核对目标、待发送文件和总大小，再明确确认发送；配置检查不会自动上传。原生 App 使用系统钥匙串保存凭据，浏览器开发界面仅在当前控制服务内暂存。指定 Jetson Orin 的 SSH 隧道流程已实测：生成、训练、回收、保存实验适配器，再在试用中选择本机 Apple GPU。直接 HTTPS 部署尚未验收；两步训练只证明流程可用。

## 9. 故障与诊断

服务中断后先重连并核实原任务。断线时不能认定远端已停止，也不要重复启动。计算完成但接收失败时，使用“只补收已有产物”，不重新计算。导出失败或取消后的部分目录不是完整包。在设备页面预览诊断摘要再保存；诊断排除任务正文、原始日志、凭据和本机路径。反馈问题时提供版本、复现步骤和经过检查的诊断文件，不附私密数据。
