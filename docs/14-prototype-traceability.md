## 4. 当前运行参数完整范围

语言设置：思考模式、上下文、最大输出、超限处理、温度、Top P、Top K、Min P、重复惩罚、停止词、流式。随机种子保留在主运行表单。

缓存和调度：KV 精度、token 容量／窗口、前缀缓存、隔离范围、Prefill 分块、分块调度、批处理 token、Decode 并发、Attention、CUDA Graph、Prefill／Decode 分离与地址。

推测解码：关闭、普通草稿、MTP、DFlash，配套草稿选择、模拟准备、推测长度／块大小和草稿精度。

硬件加载：设备、硬件后端、引擎、权重计算精度、内存上限、CPU 线程、张量并行、GPU 卸载层、Core ML 计算单元。

媒体设置：采样调度器、步数、CFG、VAE Tiling／Slicing、CPU 卸载、编译、帧数、帧率、输出采样率、音频分块、流式音频、语速。

这些控件及其保存行为属于原型范围；它们目前没有传入真实模型引擎。
