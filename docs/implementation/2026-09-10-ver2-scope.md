# Ver2.0 候选组合与验收边界

记录日期：2026-09-10。责任人：总负责人。版本编号以 [version.json](../../scripts/desktop/version.json) 为准，当前尚未冻结最终候选包。本表选择本轮组合并区分功能、效果与发布证据；不更改 1.1 设计基线，也不取消 M0—M6 的必需退出条件。

## 1. 本轮纳入的精确组合

| 范围 | 本轮组合 | 当前边界 |
| --- | --- | --- |
| 桌面 | Apple Silicon，macOS 26 及以上，Tauri；Global Cybersecurity Alliance Limited 组织签名 | 最终同源包、安装升级和恢复后回归待签署；不是已公证的对外分发包 |
| 本机语言 | Qwen2.5-0.5B-Instruct，固定来源版本，MLX 文本生成、SFT + LoRA、检查点与规则评测 | 功能已有真实证据；原 128 步候选质量失败保留，新的达标 LoRA 尚待实证 |
| 首期远端 | 指定 NVIDIA Linux 文本推理和 SFT + LoRA；同份产物到 Apple 试用 | **仍属必需范围**。远端协议与服务软件继续实施，指定设备及跨端真实证据待补，不能列为不适用 |
| 图片 | 固定 Tiny-SD，Diffusers / MPS，512×512 生成和 attention LoRA | 功能通过；既有颜色和结构质量失败保留，不称质量提升 |
| 视频 | 固定 SVD 图生视频，14 帧、7 FPS、约两秒 | 文件和执行功能通过；既有运动质量失败保留；视频训练未选入 |
| 音频 | 固定 Kokoro-82M，中文小北音色，CPU，24 kHz WAV | 功能及重复生成证据存在，仍需人工听评；ASR、音频训练、变声和音乐未选入 |
| 工作流／修订 | 图片→视频→配音分别保存；文字、配音文案、外置字幕独立版本 | 两轮运行与复用失效已验；三类修订和导出已实际核对；没有媒体合成成片 |
| M5 权重量化 | 固定 Qwen 原模型→MLX 4-bit、group 64、affine、独立 safetensors 模型 | 转换／加载／导出功能已验；新增原模型与量化候选的固定评测、准入和最终包仍在完成 |
| 本机运行优化 | 默认 auto KV / 2048 分块；低内存 v2 auto / 512；低延迟 auto / 4096 | 只声明固定本机样例的结果；原 q4 KV 质量 No-Go 保留且不可选，不等同于 q4 权重 |
| 数据市场 | 受控独立提供方协议、访问申请、下载、版本登记与原草稿返回 | 已完成受控真实 UI 与传输验证；商业提供方接入和授权不在此证据内 |
| AI 辅助 | 固定本机模型生成结构化建议，差异预览、应用和撤销 | 不自动开始运行、登记或上传；未开放远程建议不继承支持 |

模型清单、版本、依赖和设备的完整摘要见各项[验收证据](2026-09-10-current-delivery-matrix.md)，不使用表中简称代替加载检查。

## 2. M5 本轮没有开放的扩展

1.1 的 [WP-15—27](../10-work-breakdown.md) 和 [GATE-M5](../11-testing-and-acceptance.md) 按版本选择组合。本轮专项选择固定 MLX 权重量化。以下扩展继续保留需求与入口边界，不能从已安装的底层库推断支持，也不占用本轮选定组合的“通过”数量。

| 扩展 | 本轮决定与具体理由 |
| --- | --- |
| QLoRA、全参数、CPT、DPO、GRPO、PPO | 未选入。各自需要独立监督目标、更新／恢复配方及质量基线，当前只固定 SFT + LoRA |
| 合并、教师蒸馏、Heretic／Abliterix | 未选入。需另定输入兼容、来源和对照目标，不把量化输出作为这些方法的产物 |
| 普通草稿、MTP、DFlash 推测解码 | 未选入。当前没有冻结相容目标／草稿／组件组合，不能开放通用开关 |
| Core ML／ANE、GGUF 和其他转换格式 | 未选入。当前固定输出为 MLX safetensors，尚无相应转换及双向加载证据；Apple 设备存在不等于 ANE 已执行 |
| AMD／ROCm、Intel／SYCL、OpenVINO／NPU、CPU 文本 | 未选入。尚未冻结对应引擎、设备、模型和验证组合；Kokoro CPU 不代表 CPU 文本支持 |
| 扩展前缀缓存、图捕获、并发调度和分离式 Prefill／Decode | 未选入。当前只开放已验证的本机 KV／分块范围；分离服务另需服务身份、连接器与故障证据 |

这些决定不适用于首期 NVIDIA、已选模型的质量失败、基础远端恢复、最终安装升级或首次用户验收；这些仍按原计划继续。

## 3. 候选放行仍需满足的条件

- 最终同一源码、依赖、版本、签名包完成原生运行、升级／失败回滚、备份恢复及全部适用对象导出回归。
- 新达标 LoRA 的预定评测、登记、试用和独立导出回载；指定 NVIDIA→Apple 同一份适配器链。
- 本轮已选媒体的人工效果评审。功能或格式验证不得替代质量结论，原失败不得改成不适用。
- 八组窗口宽度／主题与键盘完整流程、20 次冷启动和普通交互延迟；每项区分开发浏览器与最终 App。
- 5 名目标用户使用同一最终候选，从零资源完成首次结果、保存和重启继续。开发者或代理预演不能替代。

当前状态为继续实施，未签署 M0—M6 全计划完成或发布。最新逐项进度以[当前交付矩阵](2026-09-10-current-delivery-matrix.md)为准。
