# 模型导入信任与权限说明：源码验证

本轮在模型导入检查中显示加载信任类别和实际权限边界，补齐此前接口有加载策略、界面未说明的缺口。固定公司签名 App 仍为 Ver2.4（034），不包含本轮修改；035 尚未构建，同源原生验收待完成，不提高 M2、完整 AC 或发布状态。

## 加载与权限边界

文本模型使用固定本机 MLX 加载器；媒体模型使用固定 safetensors 或 Kokoro 官方权重受限加载器。只接受已知的信任类别与加载器组合，不支持模型自定义代码；既有危险格式拒绝规则保持。独立工作进程仍使用当前用户的文件权限，未启用操作系统沙箱。

本机文件与离线加载选项不等于操作系统阻断网络；工作进程的环境变量白名单不传入应用凭证，也不等于拒绝读取凭证文件。新增 `execution_boundary` 明确这些限制，既有 `execution_scope` 三个布尔字段保留兼容，表达加载策略而非操作系统权限。

后端导入时重新核对源文件，并从实际检查结果写入权限说明，兼容缺少新字段的旧计划。前端只允许已知完整说明的模型检查结果确认导入；说明缺失、未知或不一致时显示错误并禁用确认，要求更新后重新检查。数据集与图片素材不套用模型说明。
