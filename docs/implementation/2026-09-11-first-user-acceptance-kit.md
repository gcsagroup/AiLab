# 首次用户验收材料与记录表

状态：待执行。依据[AC-25原标准](../11-testing-and-acceptance.md)。本材料不替代五名真实用户，不预填成功，也不把开发者预演计入人数。

## 执行前由负责人核实

- 使用最终核验通过的同一候选包；逐人记录版本、构建号、App摘要和组织签名，不让测试期间的重打包混入同一批次。
- 使用适用的Apple Silicon和macOS环境，确认干净安装、没有模型、项目、数据或历史。仅换一个空工作目录不能称为干净安装；不删除任何已有工作库来制造空态。
- 每人使用独立验收环境，前一人的下载、缓存和项目不预置给下一人。App内置执行器可随包提供，模型须由该用户在产品中明确准备。
- 参与者是产品面向的目标用户。只记录匿名编号U01—U05、相关经验和必要设备信息；不需要真实姓名或账户凭据。
- 观察者先记录环境与开始时间。允许产品内帮助；开发文档、开发者代点或代填须记录为人工帮助，不能隐去阻塞再判独立完成。

## 给参与者的任务说明

请在应用中选择语言模型试用，准备一个支持的模型，取得第一份真实文字结果并保存。随后正常退出并重新打开应用，找到刚才的任务和作品，继续编辑输入。可以使用应用中的帮助；遇到不理解的步骤请说出困难，观察者会记录。
