## 行为与原资料保护

恢复模式只开放正式便携备份检查、独立恢复、结果核实与明确切换；普通项目、模型、执行环境及凭据操作由宿主拒绝。原故障库的数据库、资产和失败证据不由恢复工作区连接或改写；应用资料目录会新增独立恢复会话，不能称整棵目录零变化。恢复目的地不得位于原故障库或应用资料目录内。

重试与失败回连前核对恢复目录实体、权限和会话回执。进入时冻结原工作库选择的缺失状态或普通文件身份，切换前及新服务启动后再次核对；只有新库启动成功且选择记录保存成功才解除恢复模式。迁移或保存失败回到同一恢复工作区，原故障库作为上一工作库记录。选择检查与文件改名不是跨进程原子比较交换，不声称抵抗恶意并发替换。

复制期间，界面禁止关闭并拒绝退出准备；宿主同步拒绝切换或重启。即使请求超时，退出前仍须控制服务确认后台空闲并冻结写入。未明确切换就退出会保留原工作库选择；下次进入会建立新会话，先前恢复目录保留。只有迁移数据库与回执的目录仍不能直接作为便携备份使用。
