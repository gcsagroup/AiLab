# 利用ガイド

[简体中文](../../../docs/USER_GUIDE.md) · [繁體中文](../../zh-TW/docs/USER_GUIDE.md) · [English](../../en/docs/USER_GUIDE.md) · [日本語](USER_GUIDE.md) · [한국어](../../ko/docs/USER_GUIDE.md) · [Français](../../fr/docs/USER_GUIDE.md) · [Português](../../pt/docs/USER_GUIDE.md)

現在のバージョンは **Ver2.7 (054)、技術プレビュー**です。ネイティブアプリから SSH トンネル経由で、Qwen2.5-0.5B-Instruct の Jetson Orin での生成、2 ステップの LoRA 学習、成果物の回収、同一アダプターの Apple GPU での実行を検証しました。指定モデルと環境に限った検証であり、品質向上を示すものではありません。直接 HTTPS 接続、クリーンインストール、初回利用者テスト、正式配布の検証は未完了です。検証済みの正式インストーラーや自動更新経路はありません。

対応範囲はモデル、デバイス、エンジン、精度の組み合わせによって異なります。開始前に設定を確認してください。品質実験には不合格の項目が残っており、学習の完了は品質の保証ではありません。文書は7言語で提供しますが、アプリ画面の7言語対応を意味しません。

## 1. 最初の実行

実行環境を準備したアプリでプロジェクトを作成し、テキストの試用を選びます。公式言語モデルを準備する場合は、出典、ライセンス、ダウンロード一覧を確認します。ダウンロード後はプロジェクトのモデル一覧への追加が必要です。既存の完全なモデルフォルダーも取り込めます。モデルと入力を選び、設定チェックに通ってから実行します。出力を保存すると生成物一覧に表示されます。ダウンロード、取り込み、下書き保存だけではモデルは動きません。

## 2. タスクと設定

作業画面やタスク一覧から再開します。下書きは自動保存されます。失敗した場合は再試行して保存済みを確認してください。過去の結果は元のモデルと設定を保持します。プリセットは差分を確認して適用し、再チェックします。出力上限、温度、Top-p、シード、コンテキスト予算、停止文字列、ストリーミングを設定できます。予算にはテンプレート、入力、出力の予約分を含み、超過時は拒否します。停止文字列は1行に1件、最大8件、各128文字です。省メモリ設定は遅くなる場合があります。4-bit KV キャッシュは現在使用を制限しており、重みの量子化とは別機能です。一覧末尾で古いタスクを読み込め、最終ページには完了表示が残ります。

## 3. 学習とデータ

言語の微調整は固定の SFT + LoRA 設定を使い、画像 LoRA は実験機能です。形式と有効な教師データを確認し、同一出典の漏洩を避けるため出典グループ単位で学習用と検証用に分割します。プレビュー後に適用し、原本は残します。データ、モデル、設定の変更後は再チェックが必要です。学習前に評価計画を固定し、評価用データを分けて基準モデルとアダプターを比較します。基準未達の結果は実験用のままで、品質承認済み候補には登録できません。一時停止と再開は画面の確認および利用可能なチェックポイントに従います。

## 4. メディアの処理

画像、動画、音声合成、文字起こしには、それぞれ対応モデルと環境が必要です。画像 → 動画 → 音声の処理では各段階の入力と結果を残します。上流の入力を変えると下流の古い結果は期限切れになります。再利用は明示的に選択し、新しい生成と区別します。サンプルの品質には制約があるため、画像、音声、動画を実際に確認してください。

## 5. 改訂と書き出し

本文とナレーション原稿はそれぞれ最大16000文字です。字幕は最大200件、合計16000文字、1件500文字までです。秒単位の時刻を順番に並べ、重複させず元動画の長さに収めます。文章の修正は生成設定を変えず、原稿の修正は音声を再合成しません。字幕は独立した VTT で、動画には焼き込みません。元の版か特定の改訂版を選んで書き出します。カードの原本書き出しは常に原本が対象です。フォルダーと範囲を確認し、全ファイルの保存と検証後に完了となります。アダプターには必要な基準モデルを記録しますが、その重みは既定では含めません。分割データの書き出しには原文と出典識別子が含まれるため、範囲を確認してください。

## 6. データ市場と AI 補助

提供元のアクセス条件に従ってダウンロードします。承認だけでは整合性確認や利用許可の代わりにはなりません。完全にダウンロード済みの版は一覧から確認・取り込み後、タスクへの使用を明示的に選びます。商用データ市場との完全な連携は未検証です。AI 補助は提案と差分を表示し、適用するかは利用者が決めます。適用だけではタスクは実行されません。

## 7. バックアップと復元

デバイスと環境の設定から完全バックアップを作成します。実行中、ダウンロード中、停止未確認の処理は先に解決してください。データベースと参照資産を含むため、大きなモデルには追加容量が必要です。新しいフォルダーへ復元し、明示的に切り替えます。元のデータは残ります。移行時のデータベースだけのコピーは完全バックアップではありません。旧アプリでは新しいデータを読めない場合があり、戻すには互換性のあるデータと更新前バックアップが必要です。ストレージ整理は対象を事前表示し、現在のライブラリーの未参照資産のみを扱い、復元手段を用意します。

## 8. リモート実行

サービスのアドレス、実行サービスの ID、認証情報を登録します。HTTPS 証明書は有効でホストと一致する必要があります。接続成功だけでは GPU やモデルの準備完了とはいえません。既定の実行先は新規テキストタスクだけに適用され、既存の下書きは元の設定を保持します。送信先、ファイル、合計サイズを確認して送信を承認します。設定チェックだけではアップロードしません。ネイティブアプリはシステムのキーチェーン、開発用ブラウザーは現在の制御サービスのセッション内に認証情報を保存します。指定 Jetson Orin では SSH トンネル経由の生成、学習、回収、実験アダプターの保存、試用画面でのローカル Apple GPU 実行を確認しました。直接 HTTPS 接続は未検証です。2 ステップの学習は動作確認のみです。

## 9. 問題への対処

サービス中断後は再接続し、元のタスクを確認します。切断はリモート処理の停止を意味しないため、重複起動しないでください。計算済みで転送だけ失敗した場合は、既存の出力のみを回収します。失敗・取消後の部分フォルダーは完全な書き出しではありません。デバイス設定で診断概要を確認してから保存します。タスク本文、生ログ、認証情報、ローカルパスは含めません。報告にはバージョン、再現手順、確認済み診断を添え、私的な情報を除いてください。
