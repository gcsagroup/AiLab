# GCSA AI Lab

[简体中文](../../README.md) · [繁體中文](../zh-TW/README.md) · [English](../en/README.md) · [日本語](README.md) · [한국어](../ko/README.md) · [Français](../fr/README.md) · [Português](../pt/README.md)

GCSA AI Lab は、ローカルでのモデル実行、LoRA による微調整、評価、生成物の管理を行うデスクトップアプリです。モデル、データ、タスク、出力をプロジェクトごとに保存し、作業の再開や結果の確認に使えます。

現在のバージョンは **Ver2.7 (057)、技術プレビュー**です。Ver2.7 (054) のネイティブアプリから SSH トンネル経由で、Qwen2.5-0.5B-Instruct の Jetson Orin での生成、2 ステップの LoRA 学習、成果物の回収、同一アダプターの Apple GPU での実行を検証しました。指定モデルと環境に限った検証であり、品質向上を示すものではありません。直接 HTTPS 接続、クリーンインストール、初回利用者テスト、正式配布の検証は未完了です。検証済みの正式インストーラーや自動更新経路はありません。 055 ではアップロード切断の原因表示と終了時の説明を修正し、ネイティブアプリで中断、状態確認、再転送を検証しました。054 のデバイス間モデル処理全体は再実行していません。

057 の同じ会社署名済み App で、画像→動画→中国語音声の処理を2回完了しました。個別に書き出した6ファイルは完全デコードと外部アプリでの表示・再生に成功しました。中断後の実行状態確認、終了確認、入力変更後の再実行、上流変更による下流の無効化をネイティブ画面で検証しました。同梱サービスの公開APIでは、実際のキャンセルと自然終了時に並行した更新要求のうち1件だけが成功し、再送でも結果は変わりませんでした。ワークフロー回帰テスト42件が通過しました。初回検証スクリプトの失敗とキャンセル記録は保持しています。学習は行っていません。指定構成の機能検証であり、メディア品質、M4／M6全体、5名の利用者検証、正式リリースの通過を示すものではありません。

内部試用として作業を続けています。055 では過去のバックアップ復元、更新とロールバック、エクスポートの独立利用、キーボードによるタスク、指定メディア生成を追加検証しました。業務資料の審査と実際の利用者5名によるテストは未完了で、模擬結果で代替していません。

2026-10-13 品質検証の追記：既存の Qwen2.5-7B-Instruct を使い、50 件の合成運用記録について、独立したローカル推論でベースラインと 2 回のプロンプト試験を実施しました。学習は行っていません。一部の項目は改善しましたが、事実の欠落と状態の誤判定が残り、修正版では原文の誘導的な注記に従って操作と復旧を捏造しました。どちらも採用していません。これらのサンプルは開発に使用済みで、独立した業務レビューもないため、ブラインドテストや本番品質の合格証拠にはなりません。

- テキスト生成、SFT + LoRA による微調整、基準モデルと候補の評価。
- 画像生成、実験的な画像 LoRA、動画生成、音声合成、文字起こし。動画・音声の学習は未対応です。
- データの取り込み、出典グループによる分割、実行履歴、生成物の改訂、書き出し、バックアップと復元。

対応範囲はモデル、デバイス、エンジン、精度の組み合わせによって異なります。開始前に設定を確認してください。品質実験には不合格の項目が残っており、学習の完了は品質の保証ではありません。文書は7言語で提供しますが、アプリ画面の7言語対応を意味しません。
