# Ver2.0 Candidate Combinations and Acceptance Boundaries

Recorded: 2026-09-10. Owner: overall lead. Version numbering follows [version.json](../../../../scripts/desktop/version.json); the final candidate package has not yet been frozen. This table selects the combinations for this round and distinguishes functional, quality, and release evidence. It does not change the 1.1 design baseline or remove required exit criteria for M0—M6.

<a id="1-本轮纳入的精确组合"></a>

## 1. Exact Combinations Included in This Round

| Scope | Combination for this round | Current boundary |
| --- | --- | --- |
| Desktop | Apple Silicon, macOS 26 and later, Tauri; Global Cybersecurity Alliance Limited organization signing | Final same-source package, installation/upgrade, and post-restoration regressions await sign-off; this is not a notarized external-distribution package. |

<a id="2-m5-本轮没有开放的扩展"></a>

## 2. M5 Extensions Not Opened in This Round

The 1.1 [WP-15—27](../10-work-breakdown.md) and [GATE-M5](../11-testing-and-acceptance.md) select combinations by version. This focused round selects fixed MLX weight quantization. The following extensions retain their requirements and entry boundaries. Support cannot be inferred from installed underlying libraries, and they do not contribute to the “passed” count for this round’s selected combination.

| Extension | Decision and specific rationale for this round |
| --- | --- |
| QLoRA, full-parameter training, CPT, DPO, GRPO, PPO | Not selected. Each requires independent supervision objectives, update/recovery recipes, and quality baselines; only SFT + LoRA is currently fixed. |
| Merging, teacher distillation, Heretic/Abliterix | Not selected. Input compatibility, provenance, and comparison objectives require separate definition; quantized output is not treated as an artifact of these methods. |
| Ordinary draft, MTP, DFlash speculative decoding | Not selected. No compatible target/draft/component combination is frozen, so a generic switch cannot be opened. |
| Core ML/ANE, GGUF, and other conversion formats | Not selected. Fixed output is currently MLX safetensors, with no corresponding conversion and bidirectional loading evidence. Having an Apple device does not mean ANE executed. |
| AMD/ROCm, Intel/SYCL, OpenVINO/NPU, CPU text | Not selected. Corresponding engine/device/model/verification combinations are not frozen. Kokoro CPU does not imply CPU text support. |
| Extended prefix caching, graph capture, concurrent scheduling, and disaggregated Prefill/Decode | Not selected. Only the verified local KV/chunking scope is open. Disaggregated services separately require service identity, connectors, and failure evidence. |

These decisions do not apply to first-phase NVIDIA, quality failures of selected models, basic remote recovery, final installation/upgrade, or first-time-user acceptance; those continue under the original plan.

<a id="3-候选放行仍需满足的条件"></a>

## 3. Conditions Still Required for Candidate Release

- The final package with the same source, dependencies, version, and signature must complete native execution, upgrade/failure rollback, backup restoration, and export regressions for all applicable objects.
- Predetermined evaluation, registration, trial, and independent export/reload of a new satisfactory LoRA; the designated NVIDIA→Apple chain using the same adapter.
- Human quality review of media selected in this round. Functional or format verification must not replace quality conclusions, and original failures must not be relabeled as not applicable.
- Eight window-width/theme combinations and complete keyboard workflows, 20 cold starts, and ordinary interaction latency; distinguish development-browser evidence from final-App evidence for each.
- 5 target users use the same final candidate, starting with zero resources, to obtain a first result, save, and continue after restart. Developer or agent rehearsals cannot substitute.

Current status is continued implementation, with no sign-off for completion of the full M0—M6 plan or release. The latest item-by-item progress is governed by the [current delivery matrix](2026-09-10-current-delivery-matrix.md).
