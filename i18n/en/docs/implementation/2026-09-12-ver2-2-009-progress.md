## Changes and Actual Verification in This Batch

This batch changes only the media bridge and adds one test file requiring no model. After ordinary cancellation sends a termination signal to its executor, 10 seconds are allowed for exit cleanup. On timeout, KILL is still sent, followed by at most another 2 seconds to reap the process. Thus 10 seconds is a cleanup grace period, not a total exit-duration limit. Ordinary exceptions retain a 2-second grace period. Process-group scope, the host shutdown’s 5-second policy, explicit forced stop, and handling after controller death remain unchanged.

The new `executor-process.json` records the CLI child process’s actual PID, exit code, signals sent, and cleanup duration. The bridge process’s `CANCELLED` or exit 130 does not replace the CLI exit record. If not started, PID and exit code are empty. If host or external force-killing leaves no receipt, the result must still be recorded as unknown.
