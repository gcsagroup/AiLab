Ver2.8 (063) adds manual interaction recording under Devices and environment → Diagnostics and support. Start recording, close the dialog, use the model library, device dialog, existing tasks or preset preview, then return to stop and inspect the results. Only action categories and timestamps remain in local memory; input text, task names and file paths are excluded. Select the results to save them yourself; quitting or switching libraries clears them. Unsupported system timing is reported explicitly. Missing records are never treated as zero latency, and recording does not automatically establish performance acceptance.
