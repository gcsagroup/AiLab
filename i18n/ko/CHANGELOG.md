## Ver2.7 (055) · 2026-10-10

원격 업로드 연결 끊김을 제어 서비스 충돌로 잘못 표시하던 문제를 수정했습니다. 실제 오류 원인을 보존하고 상태 확인 시 연산을 다시 제출하지 않습니다. 기본 앱에서 중단 후 상태 확인, 재연결, 새 전송 성공과 회수 파일 내용 일치를 확인했으며 기존 기록을 보존했습니다.

055는 업로드 연결 끊김 원인과 최종 상태 안내를 수정했습니다. 기본 앱에서 중단, 상태 확인, 새 전송 성공을 검증했으며 054의 전체 기기 간 모델 흐름은 다시 실행하지 않았습니다.

055 추가 검증: 앞서 AGX에서 학습한 동일한 실험용 어댑터를 기본 UI에서 내보낸 뒤, 내보내기 복사본을 번들 MLX 환경으로 독립적으로 불러와 Apple GPU에서 생성에 성공했습니다. 어댑터 해시는 일치했고 기반 모델과 내보낸 파일은 변경되지 않았으며 프로세스는 자연 종료했습니다. 추가 학습은 없었고 품질 승인 및 전체 기기 간 배포 검증은 아직 완료되지 않았습니다.

## Ver2.7 (054) · 2026-10-10

현재 버전은 **Ver2.7 (054), 기술 미리보기**입니다. 기본 앱에서 SSH 터널을 통해 Qwen2.5-0.5B-Instruct의 Jetson Orin 생성, 2단계 LoRA 학습, 결과 회수와 동일 어댑터의 Apple GPU 실행을 검증했습니다. 지정 모델과 환경에 한정된 검증이며 품질 향상을 입증하지 않습니다. 직접 HTTPS 배포, 새 환경 설치, 최초 사용자 테스트와 정식 배포 검증은 완료되지 않았습니다. 검증된 정식 설치 패키지나 자동 업데이트 채널은 아직 없습니다.

2026-10-07: 공개 문서를 7개 언어로 정리하고 내부 개발·검증 로그를 제외했으며 사용 절차를 다시 작성했습니다. 문서만 변경했으며 앱은 다시 빌드하지 않았습니다.

## Ver2.6 (053)

현재 버전은 **Ver2.6 (053), 기술 미리보기**입니다. Apple Silicon에서 지정 모델의 실행과 미세 조정을 검증했습니다. NVIDIA 기기 간 작업, 새 환경 설치, 최초 사용자 테스트와 정식 배포 검증은 완료되지 않았습니다. 검증된 정식 설치 패키지나 자동 업데이트 채널은 아직 없습니다.

- 페이지를 더 불러온 뒤 키보드 포커스를 보이는 위치에 유지하고 마지막 페이지에 완료 표시를 남깁니다.
- 텍스트 생성 수치 필드에 관련 오류를 표시하고 잘못된 값을 거부합니다. 온도와 Top-p는 유효한 소수를 받습니다.
- 고정 7B 모델의 실험 지원을 추가하고 품질 검사에 실패한 7B 양자화 KV 캐시 조합을 차단합니다.
- 생성물 버전 내보내기, 백업·복원, 출력 재수집과 진단 요약을 제공합니다. 정식 배포 및 업무 품질 검증은 미완료입니다.
