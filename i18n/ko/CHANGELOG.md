## 2026-10-14 · 로컬 매개변수 및 취소 추가 검증

동일한 회사 서명 Ver2.7(055)의 네이티브 화면에서 로컬 추론을 두 번 실행했습니다. 한 번은 입력 매개변수, 고정된 실행 설정과 성공 결과를 대조했으며, 다른 한 번은 생성 중 취소하고 프로세스 종료를 확인했습니다. 관련 테스트 101개가 통과했고 기존 검증 기록과 일상 라이브러리는 유지되었습니다. 학습이나 App 재빌드는 없었습니다. 지정 NVIDIA 장치에 현재 연결할 수 없어 원격 추가 검증은 미완료입니다. 전체 기능, 모델 품질 또는 출시 검증 통과를 의미하지 않습니다.

## 2026-10-14 · 초기 기술 및 선택 기준 정리 완료

두 장치의 초기 텍스트 구성, 데스크톱 수명 주기와 동일한 장치 간 어댑터에 대한 기술 증거를 정리하고 현재 선택 사항 및 남은 인수 검증 계획을 보완했습니다. Ver2.7(055)는 여전히 기술 미리보기입니다. 이번에는 기록만 갱신했으며 App 재빌드나 모델 실행은 없었습니다. 기술 기준 정리 완료가 모델 품질, 전체 기능 매트릭스, 실제 사용자 5명, 새 환경 설치 또는 정식 출시 검증 통과를 의미하지 않으며 출시일을 약속하지도 않습니다.

## 2026-10-14 · 데스크톱 시작·종료 및 장애 복구 검증

동일한 회사 서명의 Ver2.7(055)에서 제어 서비스 중단 안내, 재연결, App 호스트 강제 종료 후 자식 프로세스 정리, 다시 열기 복구, 종료 취소 및 정상 종료를 네이티브로 검증했습니다. 번들 제어 서비스도 중국어 문자와 공백이 포함된 경로에서 시작·종료, 충돌 후 재시작과 실패 로그를 확인했으며 관련 테스트 13개가 통과했습니다. 검증 라이브러리의 모든 업무 기록을 유지하고 원래 라이브러리 선택을 복원했습니다. 모델 실행이나 App 재빌드는 없었습니다. 이 기술 검증은 실행 중인 작업의 전체 장애 매트릭스, 품질, 실제 사용자, 새 환경 설치 및 출시 검증을 대신하지 않습니다.

## 2026-10-14 · Apple 및 NVIDIA 기술 증거 확인

지정된 Qwen2.5-0.5B-Instruct의 과거 Apple 4단계 및 NVIDIA 2단계 LoRA 학습, 실제 생성과 출력 파일 26개를 확인했습니다. 기반 모델, 토크나이저 파일, 템플릿의 식별 정보가 일치하며 관련 회귀 테스트 49개가 통과했습니다. 최소 학습·추론 기술 시험은 통과했지만 모델 품질은 아직 평가하지 않았습니다. 이번에는 새로운 학습이나 생성, 원격 연결, App 재빌드를 수행하지 않았습니다. 데스크톱 수명 주기의 나머지 증거, 전체 단계 인수 검증과 정식 출시는 아직 완료되지 않았습니다.

내부 시험 사용 추가 검증: 과거 백업 복원, 마이그레이션 실패 롤백, 054→055 업데이트와 이전 패키지 복귀가 통과했습니다. 복원 후 12종 내보내기의 콘텐츠 파일 64개를 확인했으며 원본·양자화 모델과 텍스트·이미지 어댑터를 독립 복사본에서 로드했습니다. 기본 앱의 키보드 작업, 현재 패키지의 이미지·영상·음성 생성, 실제 연산 시작 후 취소와 프로세스 종료도 확인했습니다. 모델 품질, 깨끗한 설치 또는 정식 출시 검증의 통과를 의미하지 않습니다.
