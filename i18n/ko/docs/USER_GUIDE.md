## 2. 작업과 설정

작업 공간이나 대기열에서 작업을 이어 갑니다. 초안은 자동 저장되며 실패 시 재시도 후 저장을 확인하세요. 이전 결과는 원래 모델과 설정을 유지합니다. 사전 설정의 차이를 확인하고 적용한 뒤 다시 검사하세요. 텍스트 설정에는 출력 제한, 온도, Top-p, 시드, 문맥 예산, 중지 문자열과 스트리밍이 있습니다. 문맥 예산은 템플릿, 입력과 출력 예약분을 포함하며 초과 요청은 거부됩니다. 중지 문자열은 한 줄에 하나씩 최대 8개, 각 128자입니다. 메모리 절약 설정은 더 느릴 수 있습니다. 4-bit KV 캐시는 현재 차단되며 모델 가중치 양자화와 다릅니다. 목록 끝에서 이전 작업을 불러오고 마지막 페이지에는 완료 표시가 남습니다.

프롬프트 청크가 작다고 더 빠른 것은 아니며 출력도 달라질 수 있습니다. 결과를 재현하려면 청크 한도, 모델, 정밀도, 샘플링 매개변수와 시드를 고정하세요.

## 3. 학습과 데이터

언어 미세 조정은 고정 SFT + LoRA 구성을 사용하며 이미지 LoRA는 실험 기능입니다. 가져온 형식과 유효한 지도 학습 샘플을 확인하세요. 같은 출처의 누출을 피하도록 출처 그룹별로 학습·검증 데이터를 나누고 미리 본 뒤 적용합니다. 원본은 유지됩니다. 데이터, 모델이나 설정을 바꾸면 재검사가 필요합니다. 학습 전에 평가 계획을 고정하고 평가 샘플을 분리해 기준 모델과 어댑터를 비교하세요. 기준 미달 결과는 실험용 어댑터로 남으며 품질 승인 후보로 등록할 수 없습니다. 일시 중지와 재개는 화면 확인과 사용 가능한 체크포인트를 따릅니다.

2026-10-13 품질 검증 추가: 기존 Qwen2.5-7B-Instruct로 합성 운영 기록 50건의 기준선과 두 차례 프롬프트 시험을 독립적인 로컬 추론으로 수행했으며, 학습은 하지 않았습니다. 일부 필드는 개선됐지만 사실 누락과 상태 오판이 남았고, 수정 프롬프트는 원문의 유도성 주석을 따라 작업 수행과 복구 사실을 꾸며냈습니다. 두 프롬프트 모두 채택하지 않았습니다. 이 샘플들은 개발에 사용됐으며 독립적인 업무 검토를 거치지 않아 블라인드 테스트나 운영 품질 통과의 증거가 아닙니다.

업무 기록을 정리할 때 JSON 형식이 올바르다고 사실까지 정확한 것은 아닙니다. 서비스와 노드, 시간, 실행한 작업, 후속 진행 상황과 복구 근거를 각각 확인해야 합니다. 원문의 제안, 부정 표현, 지시형 주석을 실행된 사실로 취급하지 마세요. 2026-10-13 합성 운영 기록 시험은 채택 기준을 충족하지 못했으며 출력은 여전히 사람의 검토가 필요합니다. 이 시험은 네이티브 App 품질 인수 검증이 아닙니다.

## 4. 미디어 작업

이번 미디어 범위는 위 표의 모델과 환경을 사용하는 이미지 생성, 짧은 동영상 생성 및 음성 합성입니다. 이미지 → 동영상 → 음성 작업은 단계별 입력과 결과를 보존합니다. 앞 단계 입력을 바꾸면 뒤 단계의 이전 결과가 오래된 것으로 표시됩니다. 재사용은 명시적으로 선택하며 새 생성으로 취급하지 않습니다. 현재 샘플에는 품질 한계가 있으므로 이미지, 소리와 동영상을 직접 확인하세요.

## 5. 수정본과 내보내기

본문과 내레이션 원고는 각각 최대 16000자입니다. 자막은 최대 200개, 총 16000자, 항목당 500자입니다. 시간은 초 단위로 순서대로 지정하고 겹치지 않으며 원본 영상 길이 안에 있어야 합니다. 텍스트 수정은 생성 설정을 바꾸지 않고 원고 수정은 소리를 다시 합성하지 않습니다. 자막은 영상에 삽입하지 않는 별도 VTT 파일입니다. 원본이나 특정 수정본을 선택한 뒤 내보내세요. 카드의 원본 내보내기는 항상 원본을 사용합니다. 폴더와 범위를 확인하고 모든 파일의 저장과 검증이 끝나야 완료입니다. 어댑터 패키지에는 정확한 기반 모델 의존성을 기록하지만 가중치는 기본 포함하지 않습니다. 분할 데이터 내보내기는 원문과 출처 식별자를 포함하므로 범위를 확인하세요.

## 6. 데이터 시장과 AI 도움

제공자의 접근 조건에 따라 다운로드합니다. 승인이 파일 검사나 사용 허가를 대신하지는 않습니다. 다운로드가 완료된 버전은 목록에서 검사·가져오기 후 현재 작업에 사용할지 명시적으로 선택합니다. 상용 데이터 시장의 완전한 연동은 검증되지 않았습니다. AI 도움은 제안과 차이를 보여 주고 사용자가 적용 여부를 정합니다. 적용만으로 작업이 실행되지는 않습니다.

## 7. 백업과 복원

기기 및 환경 설정에서 전체 백업을 만듭니다. 실행·다운로드 중이거나 중지 미확인인 기록을 먼저 처리하세요. 데이터베이스와 참조 자산을 포함하므로 큰 모델에는 추가 공간이 필요합니다. 새 폴더로 복원한 뒤 명시적으로 전환하며 원래 라이브러리는 유지됩니다. 데이터베이스만 있는 마이그레이션 사본은 전체 백업이 아닙니다. 이전 앱은 새 라이브러리를 읽지 못할 수 있으므로 다운그레이드에는 호환 라이브러리와 업데이트 전 백업이 필요합니다. 저장 공간 정리는 범위를 미리 보여 주며 현재 라이브러리의 미참조 자산만 처리하고 복원 기능을 제공합니다.

## 8. 원격 실행

서비스 주소, 실행기 ID와 인증 정보를 등록합니다. HTTPS 인증서는 유효하고 호스트와 일치해야 합니다. 연결 성공은 GPU나 모델 준비 완료를 뜻하지 않습니다. 프로젝트 기본 위치는 새 텍스트 작업에만 적용되고 기존 초안은 원래 위치를 유지합니다. 대상, 파일과 총크기를 확인한 후 전송을 명시적으로 승인하세요. 설정 검사는 업로드하지 않습니다. 기본 앱은 시스템 키체인에, 개발용 브라우저는 현재 제어 서비스 세션에만 인증 정보를 저장합니다. 지정 Jetson Orin에서 SSH 터널을 통한 생성, 학습, 결과 회수, 실험 어댑터 저장 후 로컬 Apple GPU 시험 실행을 검증했습니다. 직접 HTTPS 배포는 아직 검증되지 않았으며 2단계 학습은 작업 흐름 확인만을 의미합니다.

## 9. 문제 해결

서비스 중단 후 다시 연결해 원래 작업을 확인하세요. 연결이 끊겨도 원격 작업이 중지된 것은 아니므로 중복 실행하지 마세요. 계산이 끝나고 전송만 실패했다면 기존 출력만 다시 수집합니다. 실패·취소된 내보내기의 부분 폴더는 완전한 패키지가 아닙니다. 기기 설정에서 진단 요약을 미리 확인하고 저장하세요. 작업 본문, 원시 로그, 인증 정보와 로컬 경로는 제외됩니다. 문제 보고에는 버전, 재현 단계와 확인한 진단 파일을 첨부하고 비공개 데이터는 빼세요.
