# GCSA AI Lab

[简体中文](../../README.md) · [繁體中文](../zh-TW/README.md) · [English](../en/README.md) · [日本語](../ja/README.md) · [한국어](README.md) · [Français](../fr/README.md) · [Português](../pt/README.md)

GCSA AI Lab은 로컬 모델 실행, LoRA 미세 조정, 평가 및 생성물 관리를 위한 데스크톱 앱입니다. 프로젝트별로 모델, 데이터, 작업과 출력을 보관해 작업을 이어 가고 결과를 확인할 수 있습니다.

현재 버전은 **Ver3.0 (070), 기술 미리보기**입니다. Ver2.7 (054)의 기본 앱에서 SSH 터널을 통해 Qwen2.5-0.5B-Instruct의 Jetson Orin 생성, 2단계 LoRA 학습, 결과 회수와 동일 어댑터의 Apple GPU 실행을 검증했습니다. 지정 모델과 환경에 한정된 검증이며 품질 향상을 입증하지 않습니다. 직접 HTTPS 배포, 새 환경 설치, 최초 사용자 테스트와 정식 배포 검증은 완료되지 않았습니다. 검증된 정식 설치 패키지나 자동 업데이트 채널은 아직 없습니다. 055는 업로드 연결 끊김 원인과 최종 상태 안내를 수정했습니다. 기본 앱에서 중단, 상태 확인, 새 전송 성공을 검증했으며 054의 전체 기기 간 모델 흐름은 다시 실행하지 않았습니다.

모델 실험실에 가중 LoRA 병합, 로컬 오프라인 응답 증류와 Core ML·ONNX·TorchScript 변환을 구현했습니다. 병합 기반 모델과 학생은 비양자화 Qwen2.5-0.5B, 로컬 교사는 0.5B 또는 7B입니다. 실제 계산, 독립 로드와 생성, 저장 및 내보낸 파일 검증을 확인했습니다. 입력은 유지되며 산출물은 실험 모델입니다. 고정 예제 통과는 전체 품질 향상을 뜻하지 않습니다.

동일한 회사 서명 070 App에서 병합, 4단계 증류, Core ML 변환과 독립 생성(출력 9)을 실제 UI로 확인했습니다. 증류는 41/200단계에서 취소했고 재시작 후 모델과 취소 기록이 유지됐습니다. 최종 내장 런타임은 세 형식의 변환·실행·내보내기 검증을 완료했습니다. 별도 7B 교사/0.5B 학생 실험의 고정 세 문항은 교사 3/3, 학생 학습 전후 모두 2/3으로 품질 향상을 입증하지 못했습니다. 일상 라이브러리는 보존·복원됐습니다. 테스트 통과: 제어 1175개, 프런트엔드 720개, Rust 88개, 관련 재검증 87개. Rust 3개 무시, 패키징 43개 통과·1개 건너뛰기입니다.

사용: 모델 실험실에서 병합, 증류 또는 형식 변환을 선택하고 작업을 만든 뒤 검사하고 명시적으로 시작합니다. 병합은 원래 기반 모델과 일치하는 LoRA를 사용하며 비율은 0.01–1입니다. 증류 데이터는 먼저 출처 그룹별로 분할하고 단일 턴 학습 부분집합 1–64개를 선택합니다. 로컬 교사가 응답을 생성하고 학생을 1–200단계 학습합니다. 완료 후 실험 모델을 저장하고 모델 목록에서 실행하거나 내보냅니다. 실행 보고서에는 출처, 설정, 교사 응답과 비교 결과가 포함됩니다.

제한: 세 형식은 CPU·FP32·고정 128토큰이며 KV 캐시가 없습니다. Core ML의 GPU·ANE는 미검증이고 TorchScript는 상위 프로젝트가 사용 중단 권고한 내보내기 API를 씁니다. 입력과 최대 출력 합계가 한도를 넘으면 자르지 않고 거부합니다. 다중 모델 병합, 온라인·KL 증류, 증류 체크포인트 재개, 추가 구조, 동적 형상과 다른 플랫폼 검증은 미완료입니다. Heretic·Abliterix 진입점과 실행기는 없습니다. 다른 학습 방식, 추측 디코딩, 하드웨어 확장, 독립 업무 품질, 실제 사용자 5명, 클린 설치, 정식 출시 및 M5·M6도 미완료입니다.
