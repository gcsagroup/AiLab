# GCSA AI Lab

[简体中文](../../README.md) · [繁體中文](../zh-TW/README.md) · [English](../en/README.md) · [日本語](../ja/README.md) · [한국어](README.md) · [Français](../fr/README.md) · [Português](../pt/README.md)

GCSA AI Lab은 로컬 모델 실행, LoRA 미세 조정, 평가 및 생성물 관리를 위한 데스크톱 앱입니다. 프로젝트별로 모델, 데이터, 작업과 출력을 보관해 작업을 이어 가고 결과를 확인할 수 있습니다.

현재 버전은 **Ver2.7 (058), 기술 미리보기**입니다. Ver2.7 (054)의 기본 앱에서 SSH 터널을 통해 Qwen2.5-0.5B-Instruct의 Jetson Orin 생성, 2단계 LoRA 학습, 결과 회수와 동일 어댑터의 Apple GPU 실행을 검증했습니다. 지정 모델과 환경에 한정된 검증이며 품질 향상을 입증하지 않습니다. 직접 HTTPS 배포, 새 환경 설치, 최초 사용자 테스트와 정식 배포 검증은 완료되지 않았습니다. 검증된 정식 설치 패키지나 자동 업데이트 채널은 아직 없습니다. 055는 업로드 연결 끊김 원인과 최종 상태 안내를 수정했습니다. 기본 앱에서 중단, 상태 확인, 새 전송 성공을 검증했으며 054의 전체 기기 간 모델 흐름은 다시 실행하지 않았습니다.

작업이 다음 페이지에 남아 있는데도 기록이 없다고 표시하는 문제를 수정했습니다. 더 불러오면 기존 평가가 표시되고, 모든 작업을 불러온 뒤 기록이 없을 때만 빈 상태를 표시합니다. 관련 프런트엔드 테스트 76개를 통과했습니다. 동일한 회사 서명 058 App에서 두 프로젝트의 언어·이미지 초안 재열기, 네 종류의 진입점과 기존 결과에서 돌아가기, 이미지 실행 중 프로젝트를 전환해도 결과가 원래 프로젝트에 귀속되는 동작을 검증했습니다. 원래 라이브러리를 복원했으며 학습은 수행하지 않았습니다. 기존 품질 실패 판정은 유지되며 전체 장치 조합, 사용자 5명, 깨끗한 환경 설치와 출시 검증은 미완료입니다.

057의 동일한 회사 서명 App에서 이미지→영상→중국어 음성 워크플로를 두 번 완료했습니다. 별도로 내보낸 파일 6개는 전체 디코딩과 외부 앱 열기·재생을 통과했습니다. 네이티브 화면에서 중단 후 실행 상태 확인, 종료 확인, 입력 변경 후 재실행 및 상위 입력 변경에 따른 하위 결과 무효화를 검증했습니다. 번들 서비스의 공개 API에서는 실제 취소와 정상 완료 시 동시에 보낸 진행 요청 중 하나만 성공했으며 재전송해도 결과가 유지됐습니다. 워크플로 회귀 테스트 42개가 통과했습니다. 첫 검증 스크립트 실패와 취소 기록은 보존했습니다. 학습은 수행하지 않았습니다. 지정 조합의 기능만 검증한 것으로, 미디어 품질, 전체 M4/M6, 사용자 5명 검증 또는 정식 출시 통과를 뜻하지 않습니다.

내부 시험 사용 단계로 진행합니다. 055에서 과거 백업 복원, 업데이트와 롤백, 내보낸 파일의 독립 사용, 키보드 작업 및 지정 미디어 생성을 추가 검증했습니다. 업무 자료 검토와 실제 사용자 5명의 테스트는 미완료이며 모의 결과로 대체하지 않았습니다.

2026-10-13 품질 검증 추가: 기존 Qwen2.5-7B-Instruct로 합성 운영 기록 50건의 기준선과 두 차례 프롬프트 시험을 독립적인 로컬 추론으로 수행했으며, 학습은 하지 않았습니다. 일부 필드는 개선됐지만 사실 누락과 상태 오판이 남았고, 수정 프롬프트는 원문의 유도성 주석을 따라 작업 수행과 복구 사실을 꾸며냈습니다. 두 프롬프트 모두 채택하지 않았습니다. 이 샘플들은 개발에 사용됐으며 독립적인 업무 검토를 거치지 않아 블라인드 테스트나 운영 품질 통과의 증거가 아닙니다.

- 텍스트 생성, SFT + LoRA 미세 조정, 기준 모델과 후보 평가.
- 이미지 생성과 실험용 이미지 LoRA, 동영상 생성, 음성 합성 및 전사 기능 진입점. 동영상·오디오 학습은 제공하지 않습니다.
- 데이터 가져오기, 출처 그룹별 분할, 실행 기록, 생성물 수정본, 내보내기, 백업 및 복원.

지원 여부는 모델, 기기, 엔진과 정밀도의 조합에 따라 다릅니다. 실행 전에 설정 검사를 확인하세요. 기존 품질 실험에는 실패 항목이 남아 있으며, 학습 완료가 품질 통과를 뜻하지는 않습니다. 문서는 7개 언어로 제공하지만 앱 화면의 7개 언어 지원을 의미하지는 않습니다.
