# M4 圖片與視頻獨立執行證據

2026-09-10，本機 Apple M5 Max、128 GiB 內存、macOS 26.6.2。圖片生成與 LoRA、SVD 圖生視頻與獨立重載的功能通過；圖片質量部分失敗，視頻近乎靜止，明顯運動質量未通過。這裡不是 `GATE-M4` 產品驗收報告。

## 圖片：實際生成、訓練與重載

證據根目錄：`.artifacts/m4-media/acceptance-v2`。固定 Tiny-SD revision、完整模型文件摘要、配方及環境見每個結果的 `generation.json`；凍結方案見 `frozen-plan.json`；匯總見 `acceptance.json`。運行前凍結了 4 張訓練源圖的種子、兩組獨立評測提示詞/種子和重載誤差閾值。

訓練報告在 `lora/training.json`，產物為 `lora/pytorch_lora_weights.safetensors`。訓練 loss 為隨機 timestep 去噪 MSE，不能比較首尾 loss 推導質量提高；本試驗也沒有做訓練恢復。

獨立產物核驗 `independent-artifact-audit.json` 使用標準庫、PIL 和 NumPy，未載入模型或原驗收腳本；核驗了全部 9 張 PNG、對應浮點像素、文件摘要、同一基座身份、訓練數據與 LoRA 摘要、執行器源碼摘要，以及 10 個不同生成/訓練進程身份。

本次執行器與依賴 lock 另存於 `executors`，入口源碼 SHA 與全部生成/訓練報告一致；後續產品集成修改源碼時，仍可核對當次真實運行版本。

<a id="图片质量有明确失败项"></a>

## 圖片質量：有明確失敗項

已直接查看兩組 PNG，詳細觀察保存在 `visual-review.json`。藍色陶瓷杯在基座與候選里都可辨，杯口和杯身形狀發生變化。紅壺提示實際生成白壺與紅背景，候選還多出紅杯，茶壺把手結構異常；紅色屬性、單物體和結構質量未通過。這裡的 LoRA 有效指實際訓練權重被重新加載並影響輸出，不表示質量改善。

這不是盲評，也沒有用戶業務素材、品牌一致性、廣泛種子、文字準確度或視頻連續性評測。4 張訓練圖均由同一基座生成，只作為來源明確的技術試驗數據。

另逐張查看了訓練源圖：101/103 為紅白配色壺，102 的把手呈額外壺嘴狀，104 有第二個白色小壺。它們與統一的紅壺 caption 存在顏色、結構、數量偏差，不能通過業務訓練數據質量准入；原凍結數據和實際訓練證據保留，不事後改 caption 或篩選成功樣例。

<a id="保留的失败与修复"></a>

## 保留的失敗與修復

首次 `acceptance-v1` 已生成真實 PNG，但上游 scheduler 的 `lambda_min_clipped=-inf` 不能寫入嚴格 JSON，流程在報告寫出失敗。現將該無界默認值顯式保存為對象並補充單測，重新建立 `acceptance-v2` 完整執行通過；沒有覆蓋舊輸出或把無完整報告的 v1 當作成功證據。

<a id="视频真实-svd独立重载与解码"></a>

## 視頻：真實 SVD、獨立重載與解碼

固定源 4,509,208,405 字節已全部下載，三個 fp16 權重通過官方 LFS SHA256，元數據通過 Git blob 摘要。首個視頻在 `.artifacts/m4-media/video-acceptance-v1`，另一個 Python 進程同配方重載在 `video-acceptance-repeat-v1`。輸入為已檢查的基座藍杯 PNG，等比縮放補邊到 1024×576；完整原圖與條件圖摘要均已凍結。

兩次都完成原生 SVD 的 25 步時序生成，得到 14 幀、7 FPS、2 秒的 H.264 MP4；全部浮點幀有限，FFprobe 實際計幀及 FFmpeg 全幀獨立解碼通過。兩個不同進程的凍結參數完全一致，浮點幀最大差 0.0，MP4 SHA256 同為 `53913f16d15d779939c4579479362bc884fe67b8449972d752e67d1294c51cad`。生成部分分別耗時 118.53 秒、132.58 秒；首次可能與暫停的文本訓練有設備駐留重疊，這些不是獨佔性能基準。沒有啓用 MPS 算子回退。

直接查看條件圖與第 0/6/13 幀：藍杯主體和背景保留，僅有極輕微輪廓、紋理抖動，畫面近乎靜止。因此真實推理與媒體編碼功能通過，但明顯運動質量未通過，不能以幀 SHA 不同宣傳鏡頭或商品動作。匯總見 `.artifacts/m4-media/video-repeat-and-visual-review.json`；各次的 `acceptance.json`、浮點幀 `pixels.npy`、14 張 PNG、解碼清單與執行器源碼快照均保留。

## 媒體產品執行橋驗證

新增 `workers/media_worker.py` 與 `adapters/media/preflight.py`，沒有修改已凍結的圖片/視頻 CLI。6 項橋 CPU 測試通過，覆蓋精確參數、完整輸入身份、額外隱藏文件/符號鏈接拒絕、輸出保護、真實子進程進度與失敗、取消後回收。4 種實際輸入預檢均通過：圖片生成、LoRA 圖片生成、圖片訓練和視頻生成；預檢只檢查實際分詞、文件、解碼和 LoRA meta 形狀，不加載基座權重。

真實橋驗收在 `.artifacts/m4-media/bridge-acceptance-v2`：圖片生成→12 步訓練→本次新 LoRA 獨立生成均成功，收到完整 12 個真實 step 事件，所有封存產物摘要由獨立測試進程復核。新圖片、LoRA 和候選圖片與原先直接查看過的對應產物 SHA 完全一致。視頻在 CLI 日誌顯示實際完成第 1/25 步後發送同組 SIGTERM，橋返回 130/CANCELLED，沒有完成事件，整個進程組已消失；後續另核驗了全部原橋與模型子進程 PID 均不存在。

匯總、事件和進程核驗分別在 `acceptance.json`、各 case 的 `*.events.jsonl`、`independent-output-and-process-audit.json`。這是執行橋的實際生命週期證據，控制 API 與普通用戶 UI 工作流由主產品報告另行驗收；取消視頻不算成功視頻。
