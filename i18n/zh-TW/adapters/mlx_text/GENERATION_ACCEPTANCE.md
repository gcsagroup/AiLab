# 本機文本生成參數驗收

日期：2026-09-10。**固定本機 Qwen2.5-0.5B 的上下文預算、停止序列和流式字段已從正式 API 到真實模型生效，並完成封存正文、保存作品和配方重載檢查。** 本文只覆蓋單條文本輸入；多輪歷史裁剪和思考切換沒有開放，普通用戶界面及最終搬移安裝包由各自驗收記錄證明。

<a id="已开放合同"></a>

## 已開放合同

| 字段 | 缺省值與允許範圍 | 實際行為 |
| --- | --- | --- |
| `context_limit` | 4096；嚴格整數 128—4096 | 本次真實聊天模板與輸入 token，加完整 `max_tokens` 預留，合計不能超過預算 |
| `overflow` | 僅 `reject` | 超限拒絕，保留原輸入；當前沒有可裁剪的舊對話 |
| `stop` | 空數組；最多 8 項，每項 1—128 字符，不重復 | 字符串精確匹配；保留空格；跨輸出塊暫存可能的前綴，命中時關閉生成器，顯示和封存正文不包含命中序列 |
| `stream` | 嚴格布爾值，默認 `true` | 關閉時不發 token 增量事件；階段、取消、最終正文保存照常工作 |
| `thinking` | 僅 `default` | Qwen2.5 與本次固定模板無思考切換能力；公開能力明確不支持，不隱藏輸出冒充關閉 |

舊草稿沒有顯式提供的新增字段繼續省略，實際默認值在提交前檢查中固定保存。上述字段僅適用於文本 `generate`；訓練、評測、量化和媒體操作拒絕這些字段。停止序列按最早完成的位置生效；多個序列同時完成時，先選較早開始的位置，再按數組順序，分塊方式不改變結果。

參數進入 `mlx-inference-v2` 身份，綁定真實輸入 token、模板、模型／適配器、執行源碼、運行版本和採樣參數。檢查後修改上下文、停止序列或流式設置必須重新檢查；不能用舊身份執行新字段。原運行快照和既有證據不回寫。

<a id="最终源码实算"></a>

## 最終源碼實算

最終執行證據：`.artifacts/m2-generation/real-20260910-v2/report.json`；凍結計劃在同目錄 `frozen-plan.json`。執行器與本輪兩種模型源摘要保持不變。

每種權重各進行 7 次獨立正常生成。固定輸入為“訂單編號為 7391，金額為 82。只回答訂單編號數字。”，經真實模板後為 50 token；相同 seed、貪心採樣和 KV 配置。

| 檢查 | BF16／4 bit 權重的結果 |
| --- | --- |
| 流式默認 | 兩者輸出 `7391`，5 個引擎返回詞元（含 EOS）、5 條 token 事件 |
| 非流式默認 | 輸出字節和引擎詞元與流式完全一致，token 事件均為 0 |
| `stop=["39"]`，流式開啓／關閉 | `3` 和 `9` 跨兩個真實詞元匹配；最終只保留 `7`，引擎返回詞元從 5 減至 3；流式事件沒有洩漏停止前綴 |
| `stop=["7"]` | 首個詞元命中，最終正文為空，正常完成 |
| `stop=[" 7391 "]` | 沒有自動去掉空格；不命中，仍輸出 `7391` |
| 總預算恰好 128 | 輸入 50，加最大輸出 78，通過且未裁剪 |

額外 6 項真實邊界觀察全部通過：兩種權重各一次非流式 Prefill 事件後取消、各一次檢查後改停止詞的執行器拒絕、各一次實際總預算 129 超過 128 的檢查器拒絕。取消退出碼均為 130，沒有 token 或 completed，進程組均已回收；修改後執行返回 `INFERENCE_IDENTITY_CHANGED`，沒有正文產物；超額拒絕返回實際預算明細且沒有建立輸出目錄。非流式 Decode 取消另有 CPU 驅動覆蓋，不能把它稱作本輪真實模型 Decode 取消。

引擎返回詞元統計包含觸發停止的詞元或 EOS，可見正文排除停止序列。緩存記錄只包括每層類型、形狀、精度和字節，不包含 KV 內容；初始緩存拒絕、普通結束、停止詞命中和取消均被釋放路徑覆蓋。
