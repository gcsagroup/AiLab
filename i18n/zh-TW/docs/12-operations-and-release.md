# 安裝、運行維護與發佈計劃

版本：1.1 · 日期：2026-09-09 · 狀態：已按審計修訂的待實現運行規範；當前沒有安裝包、後台服務或生產部署。

相關文檔：[開發路線](09-development-roadmap.md)、[任務合同](07-api-and-task-lifecycle.md)、[測試](11-testing-and-acceptance.md)。

<a id="1-交付单元"></a>

## 1. 交付單元

區分桌面客戶端、控制服務、執行器、環境包、模型文件、數據、作品和報告。應用升級不默認重下全部模型，也不自動升級正在使用的訓練環境。

發佈清單包含應用版本、提交哈希、構建平台、包摘要、簽名身份、基礎依賴、可選環境、數據庫 schema、支持矩陣、已知問題和回滾說明。

<a id="2-首次安装与环境准备"></a>

## 2. 首次安裝與環境準備

1. 安裝應用，檢查基本存儲權限和可用空間。
2. 用戶選擇數據根目錄與模型緩存位置。
3. 只讀探測設備，顯示真實型號、內存、驅動和可用後端。
4. 用戶選擇要準備的運行／訓練環境，查看依賴來源、空間和操作範圍。
5. 創建獨立環境並執行最小自檢；成功後登記環境摘要。
6. 準備模型，完成下載完整性和加載檢查。
7. 執行一個真實示例任務，保存結果與配方。

首次使用驗收 AC-25 從乾淨環境出發，允許在類別內直接試用，記錄模型準備、設備檢查、首次結果和退出後續做的完整路徑。最近任務入口必須能找到生成與訓練記錄，不能只展示訓練歷史；五名目標用戶的完成情況、耗時和阻塞作為可用性證據，不能用開發者熟練操作替代。（E-01）

沒有驅動時說明需要的步驟；驅動安裝、系統權限變更和遠程服務部署不作為普通連接檢查的一部分。用戶取消準備後，現有環境和數據保持可用。

<a id="3-运行模式"></a>

## 3. 運行模式

| 模式 | 網絡與執行 | 展示規則 |
| --- | --- | --- |
| 演示模式 | 預置數據和模擬執行，無真實計算承諾 | 全局醒目標記，結果附演示來源 |
| 本地模式 | 本機已準備模型和執行環境 | 顯示實際設備、參數和產物 |
| 遠程模式 | 用戶指定服務器或已配置雲實例 | 提交前展示發送內容與目標 |

演示與真實數據目錄分開，不能在同一任務中混用模擬指標和真實指標。生產發佈包可以保留演示體驗，但必須有清晰模式邊界，模擬成功記錄不得進入正式支持報告。

<a id="4-日常运行与资源管理"></a>

## 4. 日常運行與資源管理

模型實例按模型版本、適配器、引擎、精度和加載參數標識。復用條件一致才共享；否則新建實例或明確卸載重載。用戶可以查看駐留模型、佔用來源和正在使用的任務。

關窗、退出應用和停止執行器分別定義：關窗可以保留後台任務；退出前顯示本地運行任務處理選項；遠程任務即使控制端退出也應可在重開後重新連接。沒有遠端持久執行能力時必須提示其限制。

<a id="5-日志与指标"></a>

## 5. 日誌與指標

日誌分應用、控制服務、執行器、任務四層，統一 task_id／attempt_id／environment_id。用戶界面顯示階段和中文摘要，可展開原始技術錯誤。

默認日誌不保存完整數據集、明文憑證或無關文件內容。任務輸入與輸出作為項目資產保存，訪問與清理遵循項目規則。診斷導出先生成可預覽清單，用戶選擇範圍後再導出。

指標需要聲明來源與採集間隔。無法從系統或引擎讀取的 GPU／ANE 使用率、緩存命中率或推理分段耗時顯示未測，不從進度條反推指標。

<a id="6-常见故障处理"></a>

## 6. 常見故障處理

| 故障 | 自動處理 | 用戶可選操作 | 必須保留 |
| --- | --- | --- | --- |
| 模型下載中斷 | 保存下載游標和已校驗塊 | 續傳、重新下載、取消 | 來源 revision、臨時文件狀態 |
| 文件校驗失敗 | 隔離不完整文件，不登記成功 | 刪除該臨時下載並重試 | 校驗摘要和錯誤 |
| 設備連接中斷 | 限定頻率重連和狀態查詢 | 修改連接、等待、取消本地等待 | 已知 attempt_id 和事件游標 |
| OOM | 記錄錯誤並釋放可釋放資源 | 減小參數，新建嘗試或恢復 | 原參數、日誌、可用檢查點 |
| 磁盤滿／產物傳輸或登記失敗 | 封存原 manifest，標記收集失敗並保留計算結果 | 恢復空間／連接後只補收，或另建明確的計算重試草稿 | 原嘗試終態、原產物摘要、收集記錄和未完成標記 |
| 引擎進程崩潰 | 控制服務保持可用 | 查看日誌、重試、新環境 | 退出信息和快照 |
| 暫停檢查點失敗 | 查詢執行器是繼續計算、異常退出還是未知，按狀態合同反饋 | 查看失敗原因、取消、已支持的強制停止；確認仍運行時可稍後再暫停 | 原控制命令、檢查點完整性、執行證據 |
| 取消超時／停止結果未知 | 保留 cancelling，繼續有限狀態查詢，不能顯示已停止 | 等待、查看遠端任務、已支持的強制停止 | 任務歸屬、進程樹證據、最後確認狀態 |
| 數據庫遷移失敗 | 停止新版本寫入，保留備份 | 回滾應用／恢複數據庫 | 舊庫、遷移版本和日誌 |
| 評測失敗 | 保留候選研究記錄，禁止准入 | 查看樣例、調整後新建實驗 | 固定評測規則和逐樣本結果 |

不得通過自動反復重跑昂貴訓練掩蓋故障，也不得清理用戶原始數據來“自動修復”磁盤問題。

<a id="61-计算结束后的补收aud-08"></a>

### 6.1 計算結束後的補收（AUD-08）

計算完成與作品／模型可用是兩個檢查點。遠端執行器封存完整 manifest 並保留文件後，傳輸、校驗或本地登記失敗可使用 [07 的 collections 接口](07-api-and-task-lifecycle.md) 補收；恢復操作只讀取原文件，不再加載模型計算。清單缺失、源文件損壞或保留期已過時顯示不可補收與缺失項，不能以重新訓練代替這次操作。

收集記錄單獨保存失敗、重試、取消和成功；原 failed／cancelled 嘗試及原因不變。補收成功後顯示“計算完成，產物已補收”，保留原失敗／取消提示，逐文件摘要和登記結果可查。候選仍須獨立加載和評測；已失敗的舊評測不會自動變為通過。驗收注入磁盤滿、斷傳和登記事務失敗，確認恢復前後計算啓動次數不增加，資產只登記一次。

<a id="7-备份与恢复"></a>

## 7. 備份與恢復

備份範圍：元數據庫一致快照、資產 manifest、需要保留的模型／數據／作品、任務快照、環境鎖文件、檢查點和報告。憑證只保留重新連接說明或安全存儲引用，不導出明文。

推薦允許用戶選擇完整備份或元數據／配方備份。後者必須說明大文件缺失時需要重新獲取，不能聲稱可離線恢復所有產物。

恢復先校驗 schema 與文件摘要，創建新恢復目錄，驗證後再切換當前工作區。恢復失敗不覆蓋仍可使用的原工作區。每次正式發佈前至少進行一次從實際備份恢復代表項目的演練。

<a id="8-清理与空间治理"></a>

## 8. 清理與空間治理

按類別展示空間：模型、數據原件、處理版本、檢查點、作品、運行緩存、下載臨時文件和日誌。先列出路徑、大小、引用與原因，再執行用戶選擇的清理。

優先可恢復方式。存在引用的文件不能因為“很久沒打開”就刪除；訓練檢查點若被恢復任務引用必須保留。清理完成後驗證索引、引用和剩餘空間，必要時允許撤銷。

卸載客戶端默認不刪除用戶數據根目錄。刪除模型、移除模型條目、清理引擎緩存是不同動作，文案要說明實際影響。

<a id="9-更新与回滚"></a>

## 9. 更新與回滾

應用更新先檢查是否存在本地任務和數據庫遷移。需要中斷時讓用戶選擇合適時機，不能在訓練過程中自動重啓側進程。下載的新包校驗摘要與簽名，再切換版本。

數據庫遷移採用版本化腳本和備份；不可逆遷移需要保留舊應用能夠讀取的備份副本。環境升級以新環境並存方式進行，舊任務仍可找到原依賴。模型更新產生新 ModelVersion，不能更改已有版本的文件。

回滾後驗證項目列表、任務快照、產物讀取和新任務執行。應用回滾成功不等於所有訓練環境都回滾成功，報告要分開。

<a id="10-导出与对外发布"></a>

## 10. 導出與對外發佈

<a id="101-用户产物导出器的范围aud-13"></a>

### 10.1 用戶產物導出器的範圍（AUD-13）

普通產物導出由 WP-29 明確負責：M3 交付模型／適配器／文本作品／報告的基礎導出，M4 擴展圖片／視頻／音頻及字幕修訂版本，M6 匯總四類對象在安裝包和獨立環境中的 AC-27 驗收。M5 新增轉換格式由 WP-24 提供產物與兼容條件，交給已有導出器並擴展對應驗收；WP-24 不代替通用導出器。診斷包屬於日誌排障，不能當作模型和作品導出交付。

| 導出對象 | 包含內容與依賴 | 獨立使用驗證 |
| --- | --- | --- |
| 完整模型／運行模型 | 固定權重或轉換產物、配置、所需 tokenizer／processor／模板、來源和兼容組合 | 在聲明的獨立環境加載並跑固定樣例，不能依賴原應用的未聲明緩存 |
| 適配器 | 適配器文件、目標模塊／參數、固定基座 revision 與摘要、模板及必要處理器 | 用聲明基座加載該適配器；基座可選內含或外部依賴，但必須明確列出獲取與校驗方式 |
| 作品 | 用戶選定的原版或 WorkRevision、媒體文件／文本、生成配方、來源與修訂記錄 | 文本可讀，圖片可解碼，視頻／音頻可獨立播放，字幕時間與媒體匹配 |
| 評測報告 | 基線與候選引用、固定數據／規則版本、匯總及已選擇的逐樣本結果、產物摘要 | 能從包內報告追蹤結論來源；未包含的原始樣本與模型標為外部依賴，不偽稱完整重評測包 |

字幕修訂與生成配方分別導出，清單固定作品版本；選擇“原輸出”不會帶上後來的人工校正，選擇“修訂版”仍保留修訂來源。已有報告不可因導出更改閾值或結論。（E-04）

<a id="102-计划落盘与失败恢复"></a>

### 10.2 計劃、落盤與失敗恢復

1. 用戶選擇對象、固定版本、目標格式與目錄；格式轉換需要先完成獨立轉換任務。解析內含文件和外部依賴，顯示清單、預計空間、來源材料及兼容條件。
2. `/exports/prepare` 生成不可變 ExportPlan 和摘要；缺少應內含文件、未完成資產、不可讀版本或未明確處理的依賴阻斷計劃。外部基座已明確列出時可以導出適配器，但界面必須說明需要基座才能使用。
3. 用戶執行計劃時復核源摘要、空間、目標目錄與計劃未變；創建 kind=export 的獨立任務嘗試，使用同一文件系統內的臨時目錄，不覆蓋現有完整導出包。
4. 寫入選定文件、`manifest.json`、配方、來源／修訂記錄、必要說明和逐文件校驗值。manifest 包含 schema、對象版本、相對路徑、大小、摘要、內含／外部依賴和兼容條件，禁止絕對私有路徑、明文憑證及越界符號鏈接混入。
5. 完成文件摘要、清單引用和可讀性檢查後，才原子改名為正式導出目錄並記錄完成；獨立加載／播放結果另記為使用驗證，文件完整與使用驗證分別展示。宣稱“可獨立使用”必須已有對應驗證證據，尚未驗證顯示未驗證。
6. 磁盤滿、傳輸中斷、源文件變化、用戶取消或校驗失敗保留明確臨時狀態和錯誤，不產生可誤認為完整的包。重試只重做導出打包或從已驗證文件續寫，不重訓／重生成；源摘要變化必須重新準備計劃。

相同冪等鍵返回同一導出任務，重復點擊不多次打包。取消與完成沿用任務狀態合同，已原子登記成功的包返回已完成；取消先提交則臨時文件不發佈為完整包。清理殘留臨時目錄前展示其關聯任務、大小和可恢復性。AC-27 包含四類代表對象、缺文件、外部基座、字幕版本、取消、磁盤滿與獨立環境使用，結果保留具體文件和摘要。

<a id="103-对外发布"></a>

### 10.3 對外發佈

對外上傳、模型倉庫發佈、服務器部署和創建雲資源均為獨立動作，不由導出按鈕自動觸發。

發佈前記錄分發依賴與模型／數據材料範圍；只列出實際可核查材料，不由 AI 生成授權結論。當前文檔不包含特定法律結論，也不把來源說明替代用戶的實際發佈決定。

<a id="11-发布验收清单"></a>

## 11. 發佈驗收清單

| 類別 | 必需證據 |
| --- | --- |
| 身份 | 安裝包版本、摘要、簽名、構建來源與提交一致 |
| 安裝 | 乾淨機器安裝、首次啓動、基礎環境檢查 |
| 主流程 | 已聲明範圍的真實訓練／推理／評測／保存閉環 |
| 數據 | 歷史項目升級、備份恢復、引用完整 |
| 導出 | WP-29 普通產物導出四類對象及獨立使用檢查，完整性和外部依賴明確；診斷包單獨驗收 |
| 設備 | 發佈矩陣內每個組合都有對應報告 |
| 參數 | 公開控件都有實際映射和必要測試 |
| 故障 | 暫停失敗、取消競爭、停止未知、斷連、OOM、磁盤滿、進程崩潰與只補收可解釋和恢復 |
| AI | 無自主執行、建議衝突處理、發送範圍明確 |
| 外觀 | 中文、鍵盤、深淺色和代表窗口寬度檢查 |
| 文檔 | 用戶指南、支持範圍、已知問題、回滾方法 |

任何數據丟失、錯誤項目歸屬、參數被靜默忽略、虛假成功或憑證洩露問題都阻斷發佈。未驗證硬件不應列為已支持。

## 12. 當前邊界
