# 首次用戶驗收材料與記錄表

狀態：待執行。依據[AC-25原標準](../11-testing-and-acceptance.md)。本材料不替代五名真實用戶，不預填成功，也不把開發者預演計入人數。

<a id="执行前由负责人核实"></a>

## 執行前由負責人覈實

- 使用最終核驗通過的同一候選包；逐人記錄版本、構建號、App摘要和組織簽名，不讓測試期間的重打包混入同一批次。
- 使用適用的Apple Silicon和macOS環境，確認乾淨安裝、沒有模型、項目、數據或歷史。僅換一個空工作目錄不能稱為乾淨安裝；不刪除任何已有工作庫來製造空態。
- 每人使用獨立驗收環境，前一人的下載、緩存和項目不預置給下一人。App內置執行器可隨包提供，模型須由該用戶在產品中明確準備。
- 參與者是產品面向的目標用戶。只記錄匿名編號U01—U05、相關經驗和必要設備信息；不需要真實姓名或賬戶憑據。
- 觀察者先記錄環境與開始時間。允許產品內幫助；開發文檔、開發者代點或代填須記錄為人工幫助，不能隱去阻塞再判獨立完成。

<a id="给参与者的任务说明"></a>

## 給參與者的任務說明

請在應用中選擇語言模型試用，準備一個支持的模型，取得第一份真實文字結果並保存。隨後正常退出並重新打開應用，找到剛才的任務和作品，繼續編輯輸入。可以使用應用中的幫助；遇到不理解的步驟請說出困難，觀察者會記錄。
