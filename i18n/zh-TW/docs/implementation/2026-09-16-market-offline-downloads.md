已修復完整下載在提供方目錄不可用時失去登記入口的問題。原始碼、宿主接線和真實 HTTP 瀏覽器流程通過；固定公司簽名 App 仍為 036，尚未包含本輪修復，下一候選的原生驗收待完成。完整 M4 與發行狀態不提高。[原始碼回執](../../../../.artifacts/market-offline-next-v1/source-acceptance.json)

<a id="行为与边界"></a>

## 行為與邊界

資料市場新增「查看已下載資料」。線上目錄失敗或仍在等待時，可切換到目前專案、目前已設定來源的本機完整下載；舊線上回應不能覆蓋本機清單。切換不會主動取消已發出的線上請求。本機模式隱藏申請、新下載與續傳，明確返回線上目錄後才開放原入口；登記及「用於目前任務」仍是獨立確認操作。

`GET /market/local-versions` 唯讀保存的完整下載版本，不請求提供方、不寫庫，也不假裝重新核對所有位元組。來源位址與版本摘要仍由原規則核對；僅瀏覽、未完成下載、其他專案或來源不能混入。登記繼續檢查實際檔案、格式和樣本數，保持冪等；用於原任務繼續核對草稿修訂，僅更換資料並使舊檢查失效。來源未設定、改址或中繼資料損壞仍拒絕。[後端報告](../../../../.artifacts/market-offline-next-v1/backend/review.md)

## 測試與實際介面驗證

前端新增 3 項失敗案例確認缺口，修復及補充遲到回應、換專案和登記回應不明情境後，31 項相關測試通過，型別檢查通過。後端 15 項新增及 48 項相關測試共 63 項通過，保留 1 項既有警告；宿主精確唯讀路由由 1 項失敗變為 1 項通過，68 項篩除未計作通過。首次系統工具鏈的 LLVM 符號錯誤未執行測試，保留為環境失敗；隨後使用專案既有獨立工具鏈，不改系統設定。[宿主回執](../../../../.artifacts/market-offline-next-v1/host/result.json)

真實生產市場元件置於暫時頁面，連接獨立暫時庫的實際控制 HTTP 服務。先下載 292 位元組、2 筆資料，再停止回環提供方；關閉並重開市場後，線上目錄失敗，而本機入口可登記、明確用於原草稿。草稿修訂 2→3，只有資料欄位變化，原輸入和設定保持；再開仍顯示已登記，重複登記傳回同一資料，無新增模型或執行。1280×720 畫面、捲動操作及主控台檢查通過，主控台 0 錯誤／警告；Vite 啟動的 2 項可選相依解析警告保留。頁面、控制服務與本輪開發服務已退出。[瀏覽器與 HTTP 證據](../../../../.artifacts/market-offline-next-v1/browser-http-001/result.json)

這是生產元件與真實服務的有限整合驗收，未涵蓋完整工作台、行動視口、簽名 App 原生入口或完整 M4。前端已有子代理獨立審查；後端與實際執行證據由根核對，額外瀏覽器獨審因子代理額度限制未完成，不計作通過。未存取原資料庫 SQL，未執行模型或訓練，原型與歷史失敗保留。
