# Ver2.0 候選組合與驗收邊界

記錄日期：2026-09-10。責任人：總負責人。版本編號以 [version.json](../../../../scripts/desktop/version.json) 為準，當前尚未凍結最終候選包。本表選擇本輪組合併區分功能、效果與發佈證據；不更改 1.1 設計基線，也不取消 M0—M6 的必需退出條件。

<a id="1-本轮纳入的精确组合"></a>

## 1. 本輪納入的精確組合

| 範圍 | 本輪組合 | 當前邊界 |
| --- | --- | --- |
| 桌面 | Apple Silicon，macOS 26 及以上，Tauri；Global Cybersecurity Alliance Limited 組織簽名 | 最終同源包、安裝升級和恢復後回歸待簽署；不是已公證的對外分發包 |
| 本機語言 | Qwen2.5-0.5B-Instruct，固定來源版本，MLX 文本生成、SFT + LoRA、檢查點與規則評測 | 功能已有真實證據；原 128 步候選質量失敗保留，新的達標 LoRA 尚待實證 |
| 首期遠端 | 指定 NVIDIA Linux 文本推理和 SFT + LoRA；同份產物到 Apple 試用 | **仍屬必需範圍**。遠端協議與服務軟件繼續實施，指定設備及跨端真實證據待補，不能列為不適用 |
| 圖片 | 固定 Tiny-SD，Diffusers / MPS，512×512 生成和 attention LoRA | 功能通過；既有顏色和結構質量失敗保留，不稱質量提升 |
| 視頻 | 固定 SVD 圖生視頻，14 幀、7 FPS、約兩秒 | 文件和執行功能通過；既有運動質量失敗保留；視頻訓練未選入 |
| 音頻 | 固定 Kokoro-82M，中文小北音色，CPU，24 kHz WAV | 功能及重復生成證據存在，仍需人工聽評；ASR、音頻訓練、變聲和音樂未選入 |
| 工作流／修訂 | 圖片→視頻→配音分別保存；文字、配音文案、外置字幕獨立版本 | 兩輪運行與復用失效已驗；三類修訂和導出已實際核對；沒有媒體合成成片 |
| M5 權重量化 | 固定 Qwen 原模型→MLX 4-bit、group 64、affine、獨立 safetensors 模型 | 轉換／加載／導出功能已驗；新增原模型與量化候選的固定評測、准入和最終包仍在完成 |
| 本機運行優化 | 默認 auto KV / 2048 分塊；低內存 v2 auto / 512；低延遲 auto / 4096 | 只聲明固定本機樣例的結果；原 q4 KV 質量 No-Go 保留且不可選，不等同於 q4 權重 |
| 數據市場 | 受控獨立提供方協議、訪問申請、下載、版本登記與原草稿返回 | 已完成受控真實 UI 與傳輸驗證；商業提供方接入和授權不在此證據內 |
| AI 輔助 | 固定本機模型生成結構化建議，差異預覽、應用和撤銷 | 不自動開始運行、登記或上傳；未開放遠程建議不繼承支持 |

模型清單、版本、依賴和設備的完整摘要見各項[驗收證據](2026-09-10-current-delivery-matrix.md)，不使用表中簡稱代替加載檢查。

<a id="2-m5-本轮没有开放的扩展"></a>

## 2. M5 本輪沒有開放的擴展

1.1 的 [WP-15—27](../10-work-breakdown.md) 和 [GATE-M5](../11-testing-and-acceptance.md) 按版本選擇組合。本輪專項選擇固定 MLX 權重量化。以下擴展繼續保留需求與入口邊界，不能從已安裝的底層庫推斷支持，也不佔用本輪選定組合的“通過”數量。

| 擴展 | 本輪決定與具體理由 |
| --- | --- |
| QLoRA、全參數、CPT、DPO、GRPO、PPO | 未選入。各自需要獨立監督目標、更新／恢復配方及質量基線，當前只固定 SFT + LoRA |
| 合併、教師蒸餾、Heretic／Abliterix | 未選入。需另定輸入兼容、來源和對照目標，不把量化輸出作為這些方法的產物 |
| 普通草稿、MTP、DFlash 推測解碼 | 未選入。當前沒有凍結相容目標／草稿／組件組合，不能開放通用開關 |
| Core ML／ANE、GGUF 和其他轉換格式 | 未選入。當前固定輸出為 MLX safetensors，尚無相應轉換及雙向加載證據；Apple 設備存在不等於 ANE 已執行 |
| AMD／ROCm、Intel／SYCL、OpenVINO／NPU、CPU 文本 | 未選入。尚未凍結對應引擎、設備、模型和驗證組合；Kokoro CPU 不代表 CPU 文本支持 |
| 擴展前綴緩存、圖捕獲、併發調度和分離式 Prefill／Decode | 未選入。當前只開放已驗證的本機 KV／分塊範圍；分離服務另需服務身份、連接器與故障證據 |

這些決定不適用於首期 NVIDIA、已選模型的質量失敗、基礎遠端恢復、最終安裝升級或首次用戶驗收；這些仍按原計劃繼續。

<a id="3-候选放行仍需满足的条件"></a>

## 3. 候選放行仍需滿足的條件

- 最終同一源碼、依賴、版本、簽名包完成原生運行、升級／失敗回滾、備份恢復及全部適用對象導出回歸。
- 新達標 LoRA 的預定評測、登記、試用和獨立導出回載；指定 NVIDIA→Apple 同一份適配器鏈。
- 本輪已選媒體的人工效果評審。功能或格式驗證不得替代質量結論，原失敗不得改成不適用。
- 八組窗口寬度／主題與鍵盤完整流程、20 次冷啓動和普通交互延遲；每項區分開發瀏覽器與最終 App。
- 5 名目標用戶使用同一最終候選，從零資源完成首次結果、保存和重啓繼續。開發者或代理預演不能替代。

當前狀態為繼續實施，未簽署 M0—M6 全計劃完成或發佈。最新逐項進度以[當前交付矩陣](2026-09-10-current-delivery-matrix.md)為準。
