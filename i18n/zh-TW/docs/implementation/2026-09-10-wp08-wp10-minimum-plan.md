# WP-08／WP-10 首期遠程執行軟件拆分

日期：2026-09-10。狀態：初始合同核查與實施分解記錄；後續軟件與回環驗收進展見[當前交付矩陣](2026-09-10-current-delivery-matrix.md)，NVIDIA實機仍未通過。

建議先接通一個獨立、持久的執行服務，再接一個 NVIDIA 文本推理適配器。可以在本機通過受控進程和回環 HTTP 驗證遠端協議、上傳、斷連、取消與只補收；GPU 加載、顯存釋放和同份 LoRA 回 Apple 的證據必須來自指定 NVIDIA 機器。這兩層使用同一協議，但分開記驗收結果。

<a id="1-已冻结的合同与当前缺口"></a>

## 1. 已凍結的合同與當前缺口

本次依據 [06 執行器合同與遠程執行](../06-architecture-and-adapters.md)、[07 狀態、冪等與收集](../07-api-and-task-lifecycle.md)、[04 執行位置與參數](../04-runtime-and-hardware.md)、[11 AC-18／AC-21／GATE-M2](../11-testing-and-acceptance.md) 及 [10 WP-08／WP-10](../10-work-breakdown.md)。原文文件 SHA 固定在 `.artifacts/desktop/wp08-wp10-contract-snapshot.json`，本次不修改原合同。

現有控制層只接受 MLX／本機 Apple GPU 文本組合，媒體執行器同樣是本機進程。現有 Settings 沒有遠端目標和憑證引用，未找到遠端服務註冊、輸入上傳、遠程狀態／日誌補拉或 NVIDIA 正式運行入口。本機已有的狀態版本、冪等、啓動前授權、歸屬核驗、只補收和受限文件校驗可以復用；本機通過不覆蓋遠端斷連語義。

首期沿用已經配置的服務器或實例。具體遠程主機、身份指紋、憑證和 NVIDIA 型號／驅動尚未鎖定，不從現有業務服務器或環境變量中自行搜取。執行服務使用獨立數據根和固定參數數組啓動子進程；本機協議測試直接用進程即可，不引入 Docker、集群、雲實例採購或部署平台。

<a id="3-必须保留的协议语义"></a>

## 3. 必須保留的協議語義

控制端分配穩定 `attempt_id` 與冪等鍵；遠端用 `attempt_id + snapshot_sha256` 識別同一次計算，持久記錄後才公開完整啓動授權。回包丟失後先查詢 attempt；同一編號不因為網絡重試再次調用執行器。遠端新進程啓動、控制端連接和任務執行身份分開記錄，PID 本身不能證明歸屬。

狀態、事件和產物均通過登記目標訪問。首期可選擇 SSH 隧道承載回環 HTTP：宿主校驗固定主機指紋，憑證由安全存儲提供，命令以參數數組執行，禁止跳過主機身份檢查。僅回環測試使用獨立臨時憑證和獨立測試目錄；這不替代正式 SSH／原生憑證路徑。不得在錯誤、配方、日誌、診斷或導出中寫入密鑰。

`connection_state` 與 `state` 分開；斷連只表示最後狀態待確認。取消請求沒有停止證據時保留 `stop_status=unknown`，不能顯示資源已釋放或再次提交計算。遠端事件序號單調遞增，本地按遠端實例、attempt 和序號去重，完成／取消競爭只裁決一次。

計算完成先封存只讀 manifest，遠端保留原文件，直到本地確認完整登記或用戶按明確清單清理。收集只接受原 attempt、manifest 摘要和獨立 collection 編號；不調用 run／resume、不改原摘要、不重寫原終態。原文件缺失或損壞時返回缺失清單；不能改成重新生成來冒充補收成功。

輸入準備和模型加載繼續執行受限格式與信任檢查。未知格式、自定義倉庫代碼或任意反序列化不進入首期默認路徑；受限加載失敗不能擴權重試。虛擬環境只固定依賴，不能作為文件、網絡或憑證權限隔離的證明。

<a id="4-nvidia-的首个组合与完成边界"></a>

## 4. NVIDIA 的首個組合與完成邊界

建議首個推理適配器採用固定 PyTorch／Transformers CUDA 組合，以一個明確的 safetensors 文本模型完成模型加載、流式生成、取消和卸載；選擇理由是可以先復用受限權重及 tokenizer 校驗，再將同一進程合同帶到 CUDA。具體版本、模型 revision、GPU、系統與驅動必須在真實目標確定後共同鎖定。此建議不表示已經選擇 vLLM／SGLang，也不開放未經映射的 KV、並行或推測參數。

WP-10 首期完成條件是該固定 NVIDIA 組合的真實推理與服務生命週期通過 GATE-M2 子集。CPU 夾具成功、回環服務成功或 CUDA 探測成功，均不能單獨完成 WP-10。TV-03 與 AC-26 還要求在 NVIDIA 上真實訓練得到的一份 LoRA，經傳輸／必要轉換後在指定 Apple 引擎獨立加載；不得用已有 Apple 訓練產物替代這條證據。

交付時至少保留兩份報告：一份記錄本機協議故障注入、原生目標選擇及真實文件傳輸；另一份記錄 NVIDIA 精確組合、固定輸入、有效參數、產物 SHA、取消／重連／資源釋放和必要的 LoRA 回程結果。任何缺失單列為待驗，不以一個總體“遠程通過”掩蓋。
