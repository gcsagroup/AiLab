# 模型匯入信任與權限說明：原始碼驗證

本輪在模型匯入檢查中顯示載入信任類別和實際權限邊界，補齊先前介面有載入策略、畫面未說明的缺口。固定公司簽章 App 仍為 Ver2.4（034），不包含本輪修改；035 尚未建置，同源原生驗收待完成，不提高 M2、完整 AC 或發布狀態。

<a id="加载与权限边界"></a>

## 載入與權限邊界

文字模型使用固定本機 MLX 載入器；媒體模型使用固定 safetensors 或 Kokoro 官方權重受限載入器。只接受已知的信任類別與載入器組合，不支援模型自訂程式碼；既有危險格式拒絕規則保持。獨立工作程序仍使用目前使用者的檔案權限，未啟用作業系統沙箱。

本機檔案與離線載入選項不等於作業系統阻斷網路；工作程序的環境變數白名單不傳入應用程式憑證，也不等於拒絕讀取憑證檔案。新增 `execution_boundary` 明確這些限制，既有 `execution_scope` 三個布林欄位保留相容，表達載入策略而非作業系統權限。

後端匯入時重新核對來源檔案，並從實際檢查結果寫入權限說明，相容缺少新欄位的舊計畫。前端只允許具有已知完整說明的模型檢查結果確認匯入；說明缺失、未知或不一致時顯示錯誤並停用確認，要求更新後重新檢查。資料集與圖片素材不套用模型說明。
