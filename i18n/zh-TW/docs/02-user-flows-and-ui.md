<a id="2-工作台首页"></a>

## 2. 工作台首頁

<a id="21-页面内容"></a>

### 2.1 頁面內容

- 四個入口卡片包含類別、適用目標和常見方法，主要操作統一為“開始訓練／微調”。
- 每類保留“直接運行／試用”次級入口；有運行草稿或歷史時提供“繼續上次運行”，不創建新的頂級導航。
- “繼續最近任務”展示當前項目最近任務名稱、編號、類別、狀態和下一步操作。
- 狀態操作採用用戶語言：繼續配置、查看運行、繼續評測、查看失敗原因。
- 次級入口鏈接到模型庫、數據集市場和模型實驗室，不再增加另一套“創作空間”導航。

<a id="22-继续任务规则"></a>

### 2.2 繼續任務規則

按用戶進入的訓練或運行類型，優先恢復本項目、本類別上次選擇的草稿。最近任務同時包含訓練和生成，顯示類型與下一步。沒有草稿時創建新任務；已有執行中任務時允許查看執行，但不能把它的參數當成可編輯草稿。用戶主動“新建訓練任務”始終生成新編號；運行頁的新建操作表達為新建運行，不誘導用戶誤建訓練。

切換項目時保留各項目的最近選擇、草稿與歷史。返回原項目恢復原上下文；後台任務完成時更新所屬項目的任務，不將用戶強制帶離當前頁面。

<a id="3-路径-a语言模型-sft--lora"></a>

## 3. 路徑 A：語言模型 SFT + LoRA

| 步驟 | 用戶操作 | 頁面反饋 | 校驗／失敗處理 |
| --- | --- | --- | --- |
| A1 | 工作台選擇語言與多模態 | 打開當前訓練草稿 | 沒有草稿時新建 |
| A2 | 選擇基座模型 | 展示輸入類型、版本、訓練能力 | 未準備模型指向準備入口 |
| A3 | 選擇 SFT、LoRA | 顯示所需數據和適配器產物 | 不支持組合給出原因 |
| A4 | 選擇或導入數據 | 預覽實際樣本、字段、版本 | 不匹配數據不能帶入 |
| A5 | 檢查並決定清洗處理 | 展示缺失、重復、劃分、媒體問題 | 用戶應用清洗後生成數據版本並重新檢查 |
| A6 | 設置步數、批量、學習率、環境 | 展示訓練參數與依賴摘要 | OOM 僅預測風險，不偽造實際剩餘顯存 |
| A7 | 檢查並啓動 | 顯示模型、數據、設備、費用來源、最終設置 | 不支持字段或未連接設備阻斷 |
| A8 | 執行 | 實際日誌、進度和可用檢查點 | 失敗保留現場，重試新建嘗試 |
| A9 | 評測 | 基線與候選的固定樣本對照 | 未通過者不得登記為可用候選 |
| A10 | 登記並試用 | 帶入候選模型，保留來源實驗入口 | 模型加載失敗返回產物檢查 |

“配置”分三步：模型與方法、準備數據、參數與環境。任務級頁簽為配置、運行、評測與產物。提交後配置轉只讀；修改通過“複製為新嘗試”進行。

<a id="4-路径-b从模型库直接运行"></a>

## 4. 路徑 B：從模型庫直接運行

1. 在模型庫按類別和格式篩選，查看模型的來源、版本與運行條件。
2. 若組件缺失，啓動下載／準備任務；下載期間可以離開頁面，從隊列查看進度。
3. 準備完成後點擊運行，進入對應類別的運行／試用頁，帶入該模型。
4. 輸入問題或提示詞；需要媒體時選擇素材並預覽。
5. 打開“運行參數與優化”，按分組編輯草稿，點擊“檢查並應用”。
6. 回到主表單檢查摘要，再點擊發送、生成、開始轉寫等動作。
7. 結果出現在當前頁並加入當前項目歷史；用戶可保存、比較、查看配方或載入繼續修改。

模型已下載不等於引擎可以加載。真實應用在模型清單中區分“文件完整”“格式適配”“已加載”“運行通過”。點擊運行時需要完成加載檢查。

換模型時同步檢查任務模式和素材類型，例如音頻理解換成只有圖像／視頻能力的模型，應在草稿中清除不支持的模式並說明素材影響。不能讓下拉框顯示看圖問答，提交值卻仍是音頻理解。轉換候選的默認引擎按產物格式重新選擇；沒有可用路徑時保留草稿並阻斷運行。

<a id="5-路径-c运行参数与优化"></a>

## 5. 路徑 C：運行參數與優化

<a id="51-入口和分组"></a>

### 5.1 入口和分組

主輸入區常駐“運行參數與優化”摘要，顯示引擎、硬件後端、上下文和輸出限制等關鍵參數。提供“完整設置”“設備與引擎”“緩存與加速”快捷入口。

語言與多模態設置分五組：生成與上下文、KV Cache、Prefill／Decode、推測解碼、設備與引擎。媒體模型設置為生成與加速、設備與引擎，不展示與該模型無關的語言參數。

<a id="52-编辑交互"></a>

### 5.2 編輯交互

- 打開時複製當前配置為獨立編輯草稿；取消、關閉、Escape 都放棄未應用修改。
- 切換設備或引擎後重新計算適用項，保留仍有相同語義的生成參數，並展示優化項變化摘要。
- 切換推測策略或目標模型後，不匹配的草稿組件及準備狀態失效。依賴檢查覆蓋目標、策略、草稿版本、思考模式和引擎，不能僅判斷非空或 ready。
- 不能適用的選項展示原因與準備動作，不允許出現已勾選但實際被忽略的狀態。
- “檢查並應用”返回字段錯誤及可修復原因；成功後關閉彈窗並刷新摘要，不立即生成。
- 任務執行中，本次配置只讀；用戶可以另建運行草稿，但不能改寫已提交快照。

<a id="53-常用预设与本次执行摘要"></a>

### 5.3 常用預設與本次執行摘要

提供模型默認、低內存、低延遲三類預設模板；後兩類僅在當前組合已定義且驗證後顯示可應用。模板帶版本，列出相對當前配置的具體字段變化、失效的準備狀態和模型重載要求。名稱是目標偏好，不是性能承諾；沒有實測時不顯示節省量或加速倍數。預設與手動編輯使用同一份校驗與取消流程，完整高級設置繼續保留。

主表單常駐本次設備名稱與本地／遠端位置，必要時展開數據發送範圍。摘要、發送按鈕旁提示與提交快照均讀取已應用配置，全局默認僅用於新建草稿。已有結果展示其提交時的環境，不能隨當前默認設備變化。

<a id="54-关键异常"></a>

### 5.4 關鍵異常

| 條件 | 提示與處理 |
| --- | --- |
| 輸入加輸出超過上下文 | 展示實際 token 預算；按用戶選擇拒絕或裁剪，並說明保留／刪除內容 |
| 模型不支持關閉思考 | 禁用切換並說明模板／模型限制；不使用隱藏標籤冒充關閉 |
| MTP 沒有配套預測組件 | 說明缺少模型能力與可用引擎；不允許提交該優化 |
| DFlash 未準備草稿 | 指向匹配草稿準備流程，保留已有配置 |
| ANE 選擇了原始權重 | 指向 Core ML 轉換產物要求；不聲稱原始權重已由 ANE 加速 |
| 引擎變化後 KV 格式失效 | 展示變更前後，要求用戶應用新草稿 |
| 遠程服務斷開 | 保留草稿和已收到結果，進入連接檢查／任務重連 |

<a id="6-路径-d图像--视频--配音工作流"></a>

## 6. 路徑 D：圖像 → 視頻 → 配音工作流

進入模型庫的工作流頁，選擇“商品圖 → 視頻 → 配音”。詳情顯示三步、依賴模型和準備狀態。依賴缺失時可以準備組件，但不能直接載入運行。

第一步生成商品圖，結果保持為圖像任務產物。用戶點擊帶入下一步後，視頻任務引用該圖片的資產編號，而不是複製一個失去來源的臨時文件。視頻完成後生成配音；每步可以檢查、重做或暫停繼續。最終保存時保存工作流記錄和全部選中產物引用。

第一版真實工作流採用逐步確認，不後台自動串行執行。任何一步失敗，都保留前序成功結果；重做某一步後，後續舊結果顯示“基於舊輸入”，不得自動替換成新版本。音視頻合成導出是額外能力，不能把存在獨立視頻和音頻文件稱為已經完成最終成片。

每次“載入工作流”創建獨立執行編號，各步驟固定輸入版本與嘗試編號。重新開始時本次結果為空，歷史縮略圖仍可查看，但不能自動成為本次已完成結果。用戶可以選擇“復用歷史結果”，查看原輸入與當前輸入的差異後明確關聯，記錄來源與選擇動作。

“帶入下一步”先檢查本步驟產物完整、所屬執行和輸入版本、目標類別是否可進入，再一次性提交步驟與引用。目標運行中或暫停中時，保持原步驟、輸出列表及兩個草稿均不變，提供查看阻塞任務和返回入口。解除阻塞後再次操作只推進一次。修改上游步驟生成新輸入版本，下游舊結果保留並標明基於舊輸入，不顯示為新版本完成。

<a id="7-路径-e数据市场与原任务返回"></a>

## 7. 路徑 E：數據市場與原任務返回

1. 從訓練數據步驟打開市場，記錄原項目、任務、類別和配置步驟。
2. 進入詳情查看格式、樣例、版本、提供方原文、訪問條件和用戶聲明。
3. 開放數據可下載；受限數據先填寫申請用途，由提供方處理訪問。
4. 下載完成後選擇“用於當前任務”；格式不匹配時禁用並解釋需要的數據格式。
5. 返回原任務，保留名稱、已設置參數和位置，新數據使舊技術檢查失效。
6. 若另選新建訓練，則明確創建新任務，不覆蓋原任務。

提供方批准下載只改變訪問狀態，不生成“AI 已確認授權”的標籤。導入 JSONL 後，列表切換到新數據所屬類型，並高亮導入結果，避免數據已導入卻看不見。

<a id="8-路径-f模型实验室与候选"></a>

## 8. 路徑 F：模型實驗室與候選

專項入口先說明輸入、方法和產物。行為調整可以選擇 Heretic、Abliterix 或對照；蒸餾選擇教師與學生；合併選擇兼容輸入與權重；量化選擇格式與校准方案；轉換選擇目標格式與計算環境。

執行後統一進入評測與產物。每個候選獨立展示狀態和來源。原模型與候選採用同一套樣本；候選未達標可以保存報告、調整後新建嘗試，不能僅改顯示狀態獲得登記資格。

轉換／量化產物可用於運行；需要再訓練時回到源權重。真實產品允許的後續轉換鏈由適配器聲明，不能把 Demo 的 `runtimeOnly` 簡化限制擴展成所有運行產物永久禁止轉換。

<a id="9-全局交互规则"></a>

## 9. 全局交互規則

<a id="91-空态加载和错误"></a>

### 9.1 空態、加載和錯誤

空態說明缺少什麼，並提供一個主要動作。下載、檢查、預處理、加載和生成都使用不同狀態文字。長操作顯示可取消性和當前階段；不能拿不斷增長的偽進度替代未知進度。錯誤優先定位到可修復字段，同時保留技術詳情展開入口。

<a id="92-表单与持久化"></a>

### 9.2 表單與持久化

單位緊跟標籤，例如 token、秒、Hz、GB；0、自動、不限制和未填寫具有不同語義。選項變更不得讓用戶在輸入過程中丟失焦點。草稿保存顯示最近保存狀態；離開頁面時未持久化失敗才提示用戶處理。

<a id="93-弹窗与响应式"></a>

### 9.3 彈窗與響應式

全局設置屬於應用層，運行參數屬於當前任務。彈窗有明確標題、關閉、取消和主要操作；真實客戶端需要焦點約束與關閉後焦點歸還。窄屏採用單列和換行頁簽，主要操作不被溢出隱藏；多列對照表可以局部橫向滾動，但頁面整體不得橫向溢出。

<a id="94-结果比较"></a>

### 9.4 結果比較

對照至少顯示模型、版本、輸入、種子、關鍵運行設置和結果。不同輸入或不同量化方式需要醒目標記，不能顯示為嚴格公平比較。圖片比較保留尺寸和裁剪條件；音頻比較可獨立播放；視頻比較保留幀率、時長和來源。

字幕、裁剪或其它人工修訂保存為新的作品版本，並能查看原結果和差異。“本次提交時固定配置”只顯示生成快照；編輯記錄單列。載入生成配方不會把後續人工字幕當作原始模型輸出。

<a id="10-首次使用引导"></a>

## 10. 首次使用引導

首次打開給出三個可執行步驟：準備模型、檢查設備、完成一個示例任務。用戶可以跳過並瀏覽界面。示例任務必須標注示例數據和模擬／真實模式；真實模式缺少依賴時提示準備步驟。

正式首次使用驗收從乾淨安裝、沒有模型或數據的狀態開始，包含下載／準備失敗後恢復、首次真實結果、保存和再次打開。操作全程提供界面入口；記錄用戶獨立完成率、耗時與阻塞點，不以熟悉實現的開發人員能點通替代目標用戶驗收。

訓練方法旁提供簡短解釋；上下文、KV、Prefill 等設置提供單位、影響和適用範圍。詳細技術資料放在幫助展開區，不能迫使用戶閱讀接口字段或環境命令才能完成基本操作。

<a id="11-交互验收"></a>

## 11. 交互驗收

交互驗收不是“按鈕能跳轉”。必須從明確入口完成真實用戶任務，驗證最終結果、數據保存、來源鏈和再次打開。關鍵路徑對應 [AC-01—AC-27](11-testing-and-acceptance.md)，原型與產品之間的差距見 [14](14-prototype-traceability.md)，本輪修改追蹤見 [16](16-audit-remediation-plan.md)。
