GCSA AI Lab 是供本機模型試用、LoRA 微調、評測及作品管理使用的桌面工作台。專案集中保存模型、資料、任務與輸出，方便繼續工作及追溯結果。

目前版本為 **Ver2.7（062），技術預覽**。Ver2.7（054）已在原生 App 中透過 SSH 通道驗證 Qwen2.5-0.5B-Instruct 的 Jetson Orin 生成、兩步 LoRA 訓練、產物回收，以及同份適配器在 Apple GPU 上執行。此驗證限於指定模型與環境，不代表品質提升；直接 HTTPS 部署、乾淨安裝、首次使用者測試及正式發行驗收仍未完成。目前沒有已驗收的正式安裝套件或自動更新管道。 055 修正上傳斷線後的原因提示與終態說明，並在原生 App 中驗證中斷、核實和重新傳輸；未重跑 054 的完整跨裝置模型流程。
