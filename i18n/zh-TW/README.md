# GCSA AI Lab

[简体中文](../../README.md) · [繁體中文](README.md) · [English](../en/README.md) · [日本語](../ja/README.md) · [한국어](../ko/README.md) · [Français](../fr/README.md) · [Português](../pt/README.md)

GCSA AI Lab 是供本機模型試用、LoRA 微調、評測及作品管理使用的桌面工作台。專案集中保存模型、資料、任務與輸出，方便繼續工作及追溯結果。

目前版本為 **Ver2.7（058），技術預覽**。Ver2.7（054）已在原生 App 中透過 SSH 通道驗證 Qwen2.5-0.5B-Instruct 的 Jetson Orin 生成、兩步 LoRA 訓練、產物回收，以及同份適配器在 Apple GPU 上執行。此驗證限於指定模型與環境，不代表品質提升；直接 HTTPS 部署、乾淨安裝、首次使用者測試及正式發行驗收仍未完成。目前沒有已驗收的正式安裝套件或自動更新管道。 055 修正上傳斷線後的原因提示與終態說明，並在原生 App 中驗證中斷、核實和重新傳輸；未重跑 054 的完整跨裝置模型流程。

修正任務仍在後頁時誤報「沒有任務記錄」的提示；載入後可查看既有評測，確實無記錄時才顯示空態。76 項相關前端測試通過。同一公司簽名 058 App 驗證兩專案語言／圖片草稿重開、四類入口與既有結果返回，並實測圖片執行中切換專案後結果仍歸屬原專案。原工作庫恢復，沒有訓練。舊品質失敗結論保留；完整設備矩陣、五名使用者、乾淨安裝與正式發行仍未完成。

057 現已在同一公司簽名 App 完成兩輪圖片→影片→中文配音，六份獨立匯出通過完整解碼並在外部應用程式開啟／播放。原生涵蓋中斷後的待核實提示、核實退出、修改輸入重做及上游變更失效；同包正式介面涵蓋真實取消和自然完成時的雙請求推進，僅成功推進一次，重複請求保持結果。42 項工作流迴歸通過；首次驗收腳本失敗及其取消記錄保留。沒有訓練。以上僅證明指定組合功能，不代表媒體品質、完整 M4／M6、五名使用者或正式發行通過。

目前按內部試用推進。055 已補驗歷史備份還原、升級與回復舊版、匯出後獨立使用、鍵盤任務及指定媒體生成。業務材料審查與五名真實使用者測試仍待驗，未以模擬結果替代。

2026-10-13 品質補充：現有 Qwen2.5-7B-Instruct 已在獨立本機推論中完成 50 筆合成維運紀錄的基線及兩輪提示詞試驗，未進行訓練。新提示詞改善了部分欄位，但仍有事實遺漏、狀態錯誤，修正輪還受到原文誤導附註影響而捏造操作與恢復；兩輪均未採用。這些樣本已用於除錯，未經獨立業務複核，不能作為盲測或正式環境品質通過的證據。

- 文字生成、SFT + LoRA 微調及基準／候選評測。
- 圖片生成與實驗性圖片 LoRA，以及影片生成、配音和轉寫入口。影片與音訊訓練尚未開放。
- 資料匯入、來源群組劃分、執行歷史、作品修訂、匯出與備份還原。

可執行範圍取決於模型、裝置、引擎與精度，開始前請以設定檢查結果為準。現有品質實驗仍有失敗項目，訓練完成不表示品質合格。文件提供七種語言，不代表應用程式介面支援七種語言。
