# 原权重与量化模型质量准入

日期：2026-09-10。当前结论：正式质量比较、失败门禁、报告及模型导出回读已完成；本次 MLX 4-bit 权重量化候选质量未通过，仍为实验模型，候选登记数量为 0。

## 已接入的流程

1. 原模型通过正式转换任务生成 MLX 4-bit／64／affine 模型，保存时绑定转换尝试、原权重版本和封存文件清单。
2. 新建评测可选择适配器或量化模型。量化模型固定回到其转换来源原权重；首次创建评测时固定准入方案，其他方案允许生成对照报告但不能用于准入。
3. 提交前分别核对两份完整权重、分词器、模板、方案和执行代码。两个独立子进程各加载一份模型，使用同一组问题与生成参数。
4. 登记时重新核算每条真实输出、类别汇总、回归门槛和独立进程身份，并重验转换来源及封存报告。只有显式登记成功才写入量化候选并将模型标为 `quality_approved`。
5. 模型默认引擎保持 MLX。没有产品转换来源、格式／引擎不匹配、方案替换、来源变化、证据不完整、人工项未完成或质量失败均不能准入。

此处是权重量化质量比较，不是 q4 KV 缓存验收。原 LoRA 的训练前方案要求、旧失败报告和 q4 KV 的 No-Go 结论保持有效。
