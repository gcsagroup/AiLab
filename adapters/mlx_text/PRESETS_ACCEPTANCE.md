# 本机文本运行预设与 KV 缓存实算封存

日期：2026-09-10。**原 q4/512 缓存候选 No-Go；新 auto/512 候选通过固定题无新增回归、隔离、取消与性能检查。** 本文只覆盖固定本机执行器，前端应用、提交、配方重载和最终搬移安装包另有验收，不能据此宣布完整 M2 或跨设备通过。

## 组合与证据口径

本机 Apple M5 Max、128 GiB 内存，macOS 26.6.2；Python 3.13.9、MLX 0.32.2、MLX-LM 0.31.3。模型为 Qwen2.5-0.5B-Instruct 的原 BF16 与本地 affine 4 bit/group 64 权重；模型和 LoRA 原文件摘要在各轮结束后保持不变。性能输入经真实模板分词后为 62、1022、3582 token；每项 max_tokens=128、seed=0、temperature=0、top_p=1，所有性能轮实际输出均为 128 token。

共 194 个模型进程：190 个正常完成、4 个按要求取消，其中 24 个为首步 logits 的独立只读观察进程。这个数量是执行统计，不能当作回答全部正确。原计划和 q4 失败报告保留；v2 在新目录先保存计划，再独立运行。

## 原候选的功能与质量

基础 18/18 执行成功；性能 68/68 包括 2 次暖机、54 次三轮交错对照和 12 次归因。24 层缓存均实际回读：每次初始为空，普通缓存为 KVCache，q4 为 QuantizedKVCache。长输入结束时普通 KV 45 MiB，q4 KV 12.65625 MiB。

| 权重 | 配置 | 严格固定题正确数 |
| --- | --- | --- |
| BF16 权重 | 默认 auto/2048 | 4/6 |
| BF16 权重 | 旧候选 q4/512 | 1/6 |
| BF16 权重 | 长输入低延迟 auto/4096 | 4/6 |
| 4 bit 权重 | 默认 auto/2048 | 5/6 |
| 4 bit 权重 | 旧候选 q4/512 | 0/6 |
| 4 bit 权重 | 长输入低延迟 auto/4096 | 5/6 |

固定题是加法、编号提取、裸 JSON、长文本前／中／尾代号检索。普通 auto/2048 与 auto/4096 的 12 对输出 token ID 完全相同；默认 BF16 加法答错，两个默认权重的 JSON 加了围栏，均按原规则记错。q4/512 的 6 次长检索全部失败，并出现重复和结构损坏，因此保持 No-Go。源代码复核只确认调用与上游合同一致，不能将失败根因断言为某个上游内核缺陷。

## 新 auto/512 候选

v2 只将 KV 恢复模型计算精度，保留 512 token 分块。12 个原固定题的全部输出 token ID 与原默认完全相同；原默认正确数仍为 9/12，结论是没有新增回归。12 对首步完整词表 logits 均有限、argmax 相同，6 个短题逐元素相同；6 个长题存在舍入差异，最大绝对差 0.757812，最大 RMSE 0.181574，不能称数值完全一致。

v2 另跑 36/36：18 次独立性能、8 次 A/B 请求与两种权重交错、4 次真实 LoRA 关闭／开启／关闭／开启、4 次在实际 Prefill／Decode 事件后取消、2 次取消后恢复。每次新缓存为空，重复输出分别匹配自身冷启动；适配器身份不同。4 次取消退出码为 130、无 completed，进程组自然回收约 92—123 ms；恢复输出与取消前一致。

## 性能与取舍

表中均为 3 次中位数。TTFT 从建立本次缓存前到首个引擎词元，排除模型加载；生成峰值是在生成前重置 MLX 计数后的峰值，包含已加载权重。它不是整机内存或进程 RSS。各原报告另存加载时间、Decode 速度、整个进程墙钟、RSS 和所有单次值。

auto/512 在中长输入降低了生成峰值，KV 大小保持原样，代价是首 token 更慢；短输入没有稳定内存收益。原 auto/512 归因与 v2 独立测量是不同轮次，不能合成同轮统计或使用不同时间的单次结果计算保证收益。auto/4096 在本机长输入三轮均略快于各自默认，BF16 中位 169.43→160.01 ms，4 bit 权重 166.76→160.63 ms；后者峰值从 1047.65 增到 1187.53 MiB，不能宣称通用加速或更省内存。
