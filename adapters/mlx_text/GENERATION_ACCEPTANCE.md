# 本机文本生成参数验收

日期：2026-09-10。**固定本机 Qwen2.5-0.5B 的上下文预算、停止序列和流式字段已从正式 API 到真实模型生效，并完成封存正文、保存作品和配方重载检查。** 本文只覆盖单条文本输入；多轮历史裁剪和思考切换没有开放，普通用户界面及最终搬移安装包由各自验收记录证明。

## 已开放合同

| 字段 | 缺省值与允许范围 | 实际行为 |
| --- | --- | --- |
| `context_limit` | 4096；严格整数 128—4096 | 本次真实聊天模板与输入 token，加完整 `max_tokens` 预留，合计不能超过预算 |
| `overflow` | 仅 `reject` | 超限拒绝，保留原输入；当前没有可裁剪的旧对话 |
| `stop` | 空数组；最多 8 项，每项 1—128 字符，不重复 | 字符串精确匹配；保留空格；跨输出块暂存可能的前缀，命中时关闭生成器，显示和封存正文不包含命中序列 |
| `stream` | 严格布尔值，默认 `true` | 关闭时不发 token 增量事件；阶段、取消、最终正文保存照常工作 |
| `thinking` | 仅 `default` | Qwen2.5 与本次固定模板无思考切换能力；公开能力明确不支持，不隐藏输出冒充关闭 |

旧草稿没有显式提供的新增字段继续省略，实际默认值在提交前检查中固定保存。上述字段仅适用于文本 `generate`；训练、评测、量化和媒体操作拒绝这些字段。停止序列按最早完成的位置生效；多个序列同时完成时，先选较早开始的位置，再按数组顺序，分块方式不改变结果。

参数进入 `mlx-inference-v2` 身份，绑定真实输入 token、模板、模型／适配器、执行源码、运行版本和采样参数。检查后修改上下文、停止序列或流式设置必须重新检查；不能用旧身份执行新字段。原运行快照和既有证据不回写。

## 最终源码实算

最终执行证据：`.artifacts/m2-generation/real-20260910-v2/report.json`；冻结计划在同目录 `frozen-plan.json`。执行器与本轮两种模型源摘要保持不变。

每种权重各进行 7 次独立正常生成。固定输入为“订单编号为 7391，金额为 82。只回答订单编号数字。”，经真实模板后为 50 token；相同 seed、贪心采样和 KV 配置。

| 检查 | BF16／4 bit 权重的结果 |
| --- | --- |
| 流式默认 | 两者输出 `7391`，5 个引擎返回词元（含 EOS）、5 条 token 事件 |
| 非流式默认 | 输出字节和引擎词元与流式完全一致，token 事件均为 0 |
| `stop=["39"]`，流式开启／关闭 | `3` 和 `9` 跨两个真实词元匹配；最终只保留 `7`，引擎返回词元从 5 减至 3；流式事件没有泄漏停止前缀 |
| `stop=["7"]` | 首个词元命中，最终正文为空，正常完成 |
| `stop=[" 7391 "]` | 没有自动去掉空格；不命中，仍输出 `7391` |
| 总预算恰好 128 | 输入 50，加最大输出 78，通过且未裁剪 |

额外 6 项真实边界观察全部通过：两种权重各一次非流式 Prefill 事件后取消、各一次检查后改停止词的执行器拒绝、各一次实际总预算 129 超过 128 的检查器拒绝。取消退出码均为 130，没有 token 或 completed，进程组均已回收；修改后执行返回 `INFERENCE_IDENTITY_CHANGED`，没有正文产物；超额拒绝返回实际预算明细且没有建立输出目录。非流式 Decode 取消另有 CPU 驱动覆盖，不能把它称作本轮真实模型 Decode 取消。

引擎返回词元统计包含触发停止的词元或 EOS，可见正文排除停止序列。缓存记录只包括每层类型、形状、精度和字节，不包含 KV 内容；初始缓存拒绝、普通结束、停止词命中和取消均被释放路径覆盖。
